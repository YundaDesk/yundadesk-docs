# Manage Yuna tasks and long-term memory

Yuna tasks collect events that need attention. Yuna long-term memory reduces repeated instructions across your merchant-team conversations.

## Yuna tasks

Common tasks include pending learning, failed AI runs, channel delivery failures, skill regression tests, and proactive outreach confirmations. Selecting a task should open the relevant detail page. Ignoring a task changes the reminder state; it should not erase the original log or business record.

Handled and ignored tasks remain available in task history. The Inbox is a reminder surface, not the only source of audit history.

## Yuna long-term memory

Yuna can remember:

- workspace-wide reporting and operating preferences;
- expression or workflow preferences for the current team member;
- confirmed context that is useful across sessions.

Use the Yuna memory page to view, correct, delete, or clear a scope. Memory is available by default to support answers. When memory is temporarily unavailable, Yuna should continue working and explain the limitation.

## What not to store

Prices, refund rules, customer commitments, and standard response policies must be managed through knowledge or learning review, not only in Yuna memory. Customer preferences belong in customer memory. Never store passwords, keys, or payment information.
