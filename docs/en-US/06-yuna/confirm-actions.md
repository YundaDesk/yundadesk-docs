# Answer Yuna confirmation questions

When a request lacks a target, scope, or handling choice, Yuna displays a choice card above the composer instead of guessing.

## Use the card

1. Read the question and every option.
2. Select the choice that matches your intent.
3. Wait for the processing state to finish.
4. Inspect the next step, draft, or confirmation card.

## Common choices

Typical choices include draft only, preview before confirmation, complete an allowed low-risk action now, or cancellation.

## If nothing follows

If nothing follows, do not click repeatedly. Check whether processing continues, a capability is missing, or the task remains after refresh. When Yuna promises a confirmation artifact, that draft or card must actually appear.
