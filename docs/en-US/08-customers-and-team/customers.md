# Manage customer profiles

Customer profiles bring together identity, source channels, conversation history, labels, notes, and customer memory so the team understands context before replying.

## Find a customer

Open Customers and search by name, contact information, labels, or the filters available on the page. A customer may use different identities across channels. YundaDesk merges them only when there is a reliable identity relationship.

## What a profile can contain

- connected channel identities and source;
- past conversations and recent interactions;
- team labels, notes, and follow-up items;
- AI memory that applies only to this customer;
- order or behavior summaries from connected systems.

Visible fields depend on connected channels, apps, and workspace capabilities. Order or behavior data cannot appear when no source is connected.

## Maintain useful context

Use labels for team filtering, notes for verified facts, and customer memory for durable preferences the AI should apply. Do not record an unverified inference as fact, and avoid sensitive data that is not needed for service.

## Correct or delete data

Correct inaccurate labels, notes, and memory promptly. Use the product's governed data process for customer export, correction, or deletion requests.
