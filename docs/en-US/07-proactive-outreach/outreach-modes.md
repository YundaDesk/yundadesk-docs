# Choose an outreach mode

Outreach defines when to contact whom. Channel delivery defines how the message is sent. Only modes currently available to the workspace can be used.

## Private outreach

Use it for a clearly identified customer. The normal flow locates the customer, prepares content, and requests confirmation before sending.

## Segmented outreach

Use real customer properties or behavior to build a target group. The target set must come from connected data rather than keyword guesses.

## Broadcast

Use a clearly defined channel or audience for one notice. If broadcast or segmentation is marked Not available on the current page, Yuna must explain the gap instead of pretending to create a send job.

## Scheduled or event-triggered outreach

Use a real event, delay, or specified time. Cart and payment events must come from a store integration; a visitor chat cannot be treated as an order event.

To repeat customer outreach, open **Yuna → Automations** and select **Set up manually**. If **Customer outreach** is available, select the executing Agent. Select existing outreach when it is ready; otherwise, select **Prepare customer outreach with Yuna**, confirm the audience, channel, and message, then return. Finally, select On demand, Every day, Weekdays, or Every week. Every send still requires a person to review and approve the frozen audience and message.
