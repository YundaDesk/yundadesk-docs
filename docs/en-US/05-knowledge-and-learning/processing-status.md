# Understand knowledge processing status

Knowledge must be parsed, compiled, and indexed before it becomes available for answers.

## Common states

- **Processing:** Content is still being prepared and is not ready for acceptance testing.
- **Searchable or completed:** The current version succeeded and can be tested.
- **Failed:** The current job did not finish; the previous successful version may remain active.
- **Update pending:** Source content changed but the new version is not current yet.

## Verify real use

Wait for completion, select **Test knowledge**, ask a directly answerable question, open the answer details, and confirm that the current knowledge source was used instead of an unrelated skill or model knowledge.

More generated items do not prove quality. A grounded, explainable answer is the acceptance result.
