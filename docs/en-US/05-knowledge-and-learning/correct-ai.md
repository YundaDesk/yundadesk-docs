# Correct an AI answer

**Correct AI** sends a wrong customer answer into governed relearning. It is not a like/dislike button and does not send a replacement message to the customer.

## Submit a correction

1. Find the wrong AI answer in the Inbox.
2. Select **Correct AI**.
3. Explain what was wrong and why it should change.
4. Provide the correct answer or handling method for next time.
5. Choose the appropriate scope and submit.

YundaDesk keeps the original answer, correction, and source conversation, then creates a learning suggestion. It affects the AI only after review and adoption.

## Write a useful correction

Do not write only “wrong answer” or “bad tone.” Identify the incorrect fact, applicable conditions, correct answer, and exceptions. Use customer scope for one person's preference. Use knowledge or skills for policies shared by all customers.

## Verify the result

After adoption, ask several different phrasings in the Playground and inspect answer details for the new version. Confirm the change with a correct answer in real reception. If an old answer still appears, check conflicting knowledge, skill state, and active version.
