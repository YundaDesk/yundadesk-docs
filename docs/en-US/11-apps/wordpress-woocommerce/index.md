# WordPress/WooCommerce

YundaDesk uses one WordPress plugin. A regular WordPress site can use live chat, AI support, and the Widget. When WooCommerce is detected, the same plugin adds optional read-only store capabilities.

- [Install the YundaDesk plugin on WordPress](./install-yundadesk.md)
- [Connect a WordPress site to YundaDesk](./connect-yundadesk.md)
- [Enable the read-only WooCommerce enhancement](./enable-woocommerce.md)
- [Understand WordPress and WooCommerce data and permissions](./data-and-permissions.md)
- [Deactivate, disconnect, uninstall, and use privacy tools](./lifecycle-privacy-troubleshooting.md)

The WooCommerce enhancement does not require a second PHP plugin. YundaDesk reads store data only after a site administrator separately approves read-only access.
