# SHOPLINE guide

Install YundaDesk from the SHOPLINE App Store, confirm the connection to your YundaDesk workspace, then enable **YundaDesk Chat** in the current store theme. Check the data connection, storefront chat display, and message delivery separately.

**Already connected your store and just need the chat button to appear?** Go to [Enable and verify SHOPLINE storefront chat](./enable-storefront-chat.md).

| Understand permissions, connection status, and orders | [Store data, permissions, and connection status](./data-and-status.md) |
| Resolve problems, reauthorize, or uninstall | [Troubleshooting and connection management](./troubleshooting-and-lifecycle.md) |

## From installation to serving customers

1. Install and authorize the public YundaDesk app in SHOPLINE.
2. Sign in to YundaDesk, check the store and workspace, and confirm the connection.
3. Enable **YundaDesk Chat** in the current theme's **App embeds**, then save.
4. Return to YundaDesk, open the storefront and check, then verify a message in both directions.

**Store data: Connected** confirms the data connection, not that storefront chat is visible. **Embedded** confirms chat loaded during the current check, not that messages have been delivered. For automated replies, continue with [Configure an Agent and bind its channel](../../04-ai-customer-service/configure.md).
