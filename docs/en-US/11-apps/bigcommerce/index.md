# BigCommerce

YundaDesk connects through the BigCommerce single-click installation flow. After installation, support teams can view read-only customer, order, and product context in the Inbox and enable the YundaDesk Widget on compatible BigCommerce storefronts.

- [Install and authorize the YundaDesk BigCommerce app](./install-bigcommerce-app.md)
- [Sync store data, enable storefront chat, and work in the Inbox](./use-yundadesk-with-bigcommerce.md)
- [Understand data permissions, multi-user access, uninstall, and troubleshooting](./data-permissions-and-lifecycle.md)

YundaDesk does not ask you to copy JavaScript or paste API keys. A store administrator must explicitly confirm the workspace connection and enable the Widget for each storefront.
