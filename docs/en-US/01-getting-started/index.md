# Getting started

If you are new to YundaDesk, read these articles in order:

1. [Meet YundaDesk](./overview.md)
2. [15-minute quick start](./quick-start.md)
3. [Sign in and enter your workspace](./account-and-login.md)
4. [Invite team members](./invite-your-team.md)
