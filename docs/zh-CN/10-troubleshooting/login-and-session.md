# 登录或会话无法激活

登录成功需要账号有效、工作区可用，并且浏览器能保存当前会话。

## 先尝试

1. 刷新登录页并重新输入账号；
2. 确认使用正确的 YundaDesk 地址；
3. 检查浏览器是否阻止必要的 Cookie 或本地存储；
4. 尝试无痕窗口，排除旧会话冲突；
5. 请管理员确认账号和工作区没有被停用。

## 仍然失败

记录发生时间、浏览器、页面地址和完整错误提示。不要发送密码、验证码、访问令牌或浏览器 Cookie。

## 频繁被退出

检查是否在多个环境使用同一地址、系统时间是否正确，以及浏览器扩展是否清理站点数据。持续发生时联系管理员查看登录审计。
