# 搜索和筛选会话

使用搜索和筛选可以缩小会话范围，避免在长列表中逐条查找。

## 使用搜索

输入客户名称或页面支持的其他客户信息。搜索结果只会显示你有权查看的工作区数据。

## 使用筛选

根据当前页面提供的选项筛选渠道、接待状态、负责人、未读或其他状态。完成后清除筛选可恢复完整列表。

## 找不到会话

1. 清除已有筛选；
2. 检查是否进入正确工作区；
3. 尝试使用客户在渠道中的显示名称；
4. 确认你拥有查看该会话的权限；
5. 检查渠道消息是否真正进入系统。
