# 搜索和筛选会话

使用搜索和筛选可以缩小会话范围，避免在长列表中逐条查找。

## Inbox「我的」和「已结束」是什么意思？

- **我的**：显示当前分配给你、尚未结束的接待会话。它不是你曾经接待过的全部客户记录；会话转交给别人或结束后，不再属于「我的」。
- **已结束**：查看已经结束接待的会话和历史消息。「已结束」表示本次接待已关闭，不代表客户的问题一定已解决，也不会删除历史消息。判断问题是否解决，还需要查看客户诉求、回答和实际处理结果。

同一客户可以有已结束的历史接待，也可以再次进入新的接待。在「我的」找不到刚结束的会话时，切换到「已结束」再搜索该客户；不要把接待状态当作问题解决结果。

## 使用搜索

输入客户名称或页面支持的其他客户信息。搜索结果只会显示你有权查看的工作区数据。

## 使用筛选

根据当前页面提供的选项筛选渠道、接待状态、负责人、未读或其他状态。完成后清除筛选可恢复完整列表。

会话默认没有优先级。在工作台第一栏的「优先级」区域，可以按「紧急 / 高 / 中 / 低」筛选当前收件箱中的会话。入口位于渠道筛选上方；再次选择当前级别可恢复全部会话。打开会话后，可通过右上角的「设置优先级 / 优先级：当前级别」按钮设置或清除。优先级只用于标记和筛选，不会改变会话列表或消息的原有排序。

## 找不到会话

1. 清除已有筛选；
2. 检查是否进入正确工作区；
3. 尝试使用客户在渠道中的显示名称；
4. 确认你拥有查看该会话的权限；
5. 检查渠道消息是否真正进入系统。
