# 理解消息状态

工作台中的消息可能先保存，再由渠道异步投递。不同状态代表的完成程度不同。

## 常见状态

- **处理中**：系统正在生成或投递，不要重复发送。
- **已接受**：系统已经开始处理发送，但不一定已到客户客户端。
- **已投递或已发送**：渠道确认已处理；重要消息仍建议在真实客户端抽查。
- **失败**：消息没有完成投递，需要查看失败原因后重试。

## 刷新后的判断

消息在刷新后仍然存在，才说明已经保存。回复完成后，消息顺序不应发生跳动。

## 客户是否已读你的回复

Website Widget 会话中，客户在打开的聊天窗口查看你的回复后，原来的“已发送”位置会显示“已读”。只打开网站、停留在 Widget 首页或让聊天窗口留在后台，不表示已读。

如果客户跳过了中间的消息，后面的回复会继续保留原有状态，直到连续查看到该位置。刷新工作台后仍会保留已确认的已读状态。“已读”不代表客户已经回复，也不代表会话已处理完成。其他渠道是否提供已读状态，取决于渠道支持情况。

## 谁看过客户消息

客户发来的消息下方可能显示“已读”头像组。这里展示已经把阅读位置推进到该消息的坐席；将鼠标移到头像组上，可以查看完整名单。它只表示这些坐席已经看到消息，不代表已经回复或处理完成。

## 处理失败

不要连续点击发送。先打开投递详情，确认是权限、渠道、内容限制还是外部平台问题。
