# 在 AI 与人工接待之间切换

YundaDesk 支持 AI 先接待、人工随时接管。全局接待设置和单个会话的接待状态是两个不同层级。

## 全局接待设置

**智能体** 决定哪个 Agent 负责接待，以及每个 Agent 绑定哪些渠道。渠道未绑定到可接待的 Agent 时，该渠道的新客户消息不会自动触发 AI 回复。

## 接管单个会话

在工作台打开会话，选择“接入接手”或页面对应操作。接管后：

- AI 暂停自动回复这条会话；
- 若已开启“坐席接入”提示，客户会收到一条由当前接手坐席发出的普通消息；
- 当前坐席可以直接回复客户；
- 会话状态和负责人会同步更新。

AI 接待中会显示当前 Agent 名称；选择名称可进入该 Agent 的配置页。存在其他可用 Agent 时，拥有渠道管理权限的成员还可以选择“切换 Agent”，并从弹窗中指定新的接待 Agent。

处理完成后，可根据页面操作把会话交还 AI 或结束会话。仅有一个可用 Agent 且渠道已有有效绑定时可直接交还；存在多个可用 Agent 或没有有效绑定时，先从弹窗选择 Agent。确认后，该 Agent 会同时成为渠道后续新会话的接待 Agent，并接管当前会话，不会生成一条只对当前会话生效的临时绑定。

交还前应确认 AI 已有继续接待所需的上下文和知识。

## 自动转人工

以下情况可能触发转人工：AI 缺少可靠答案、客户明确要求人工、所需应用或渠道不可用，或命中安全与业务规则。转人工不代表系统已解决问题，团队仍需在工作台完成后续处理。

## 建议做法

- 高风险承诺、退款、改价等操作保留人工确认；
- 接管后避免 AI 与人工同时发送；
- 发现 AI 回答错误时使用“纠正 AI”，不要仅在聊天中补一句而不留下学习依据。
