# 在工作台管理会话

工作台把各渠道的客户会话集中在一起。典型布局包括会话列表、聊天区和客户资料区。

## 处理一条会话

1. 从会话列表打开客户会话。
2. 查看渠道来源、历史消息、当前接待状态和客户资料。
3. 如果会话正在由 AI 接待，可先观察回答，也可以选择接入接手。
4. 输入文字或按页面支持情况发送图片、文件和表情。
5. 需要同事协助时转接会话；问题处理完成后结束会话。

消息旁的状态用于区分发送中、已发送、已送达或失败。若发送失败，按页面提示重试或查看投递详情。

### 阅读和回复邮件会话

邮件会话仍出现在同一工作台列表中。打开后，中间区域会按邮件形态展示主题、发件人、收件人、抄送和邮件正文；邮件中的 HTML 排版会在安全清洗后显示。右侧客户资料和其他会话操作保持不变。

人工接待时，先核对收件人与邮件主题，需要时展开抄送或密送。发送后，回复会继续归入原邮件线程。若正文排版、收件人或主题不正确，请先修改再发送。AI 正在接待时不会显示这些对客回复字段；你仍可添加团队内部备注，或先接入会话再回复客户。

## 提高回复效率

- 使用团队共享的快捷回复处理高频问题；
- 使用翻译功能阅读外语消息或把回复翻译成客户语言；
- 参考坐席助手提供的建议回复，但发送前仍需人工确认；
- 在客户资料中维护标签、备注和跟进信息。

### 持续翻译草稿

如果管理员已在聊天工具中启用发送翻译，你可以前往「设置 → 聊天工具 → 翻译设置」，决定是否为自己的新对话默认开启「持续翻译」；也可以打开输入框工具栏的翻译菜单，为当前会话单独开关并选择客户语言。

开启后，输入框会保留原文，并在上方显示客户将收到的译文预览；快捷回复和坐席助手建议也遵循相同规则。发送时，系统会根据最终原文重新翻译。翻译或发送失败时不会自动改发原文，草稿会保留以便修改或重试。

## 未读与通知

未读角标帮助团队定位新消息。浏览器桌面通知需要用户授权，并受个人通知设置影响。多人协作时，应避免多个坐席同时回复同一会话。

## 会话历史

结束会话不会删除历史。客户再次联系时，团队仍可以在客户档案中查看过去的沟通记录；是否创建新会话由当前会话状态和渠道行为决定。
