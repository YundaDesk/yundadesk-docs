# 创建和管理 Yuna 自动化

Yuna 自动化用于按需运行或定时重复工作。你可以把工作区任务交给一个明确的 Agent；页面提供“客户触达”类型时，也可以重复运行已经准备好的触达，并在每次发送前由人工批准。

## 开始前

- 你需要有权使用 Yuna 和管理 Agent；看不到“自动化”入口时，请联系工作区管理员检查权限。
- 工作区任务需要至少一个已启用、且有可用只读能力的 Agent。
- 只有当前成员权限和工作区状态支持时，页面才会显示“客户触达”类型。还没有可选内容时，可以直接从自动化设置中与 Yuna 准备。

## 与 Yuna 创建

1. 在主导航展开 **Yuna**，选择 **自动化**。
2. 选择 **创建**。默认会打开 Yuna；也可以打开旁边的菜单，明确选择 **与 Yuna 创建**。
3. Yuna 会先简要说明自动化的运行和安全边界，再一次询问一个必要问题。先说明希望自动完成的工作区任务即可，不必一次填写全部信息。
4. 根据 Yuna 的提问选择明确的 Agent 和运行时间。信息完整前不会创建任务。
5. 信息完整后，Yuna 会创建草稿并显示结果；回到自动化列表继续检查。

“与 Yuna 创建”只会创建工作区任务草稿，不会准备或发送客户触达。

## 手动设置

1. 在 **创建** 旁打开更多选项，选择 **手动设置**。
2. 填写执行说明。页面会根据任务说明的首句生成列表标题，不需要单独命名。
3. 选择任务类型：
   - **工作区任务**：选择一个已启用的 Agent。页面会读取该 Agent 当前可用于自动化的只读能力；结果保留在工作区。
   - **客户触达**：选择执行 Agent，再选择一项已经准备好的客户触达。如果还没有可选内容，选择 **与 Yuna 准备客户触达**，按提示确认目标受众、发送渠道、消息内容和发送限制；完成预览和确认后，返回自动化设置并选择它。每次真实发送仍需人工批准。
4. 选择 **按需运行**、**每天**、**工作日** 或 **每周**；定时任务按页面显示的时区执行。
5. 选择 **创建**。

新建自动化以草稿保存。打开详情确认任务类型、执行对象、频率和执行说明，再打开列表卡片上的开关启用。

## 运行、暂停和编辑

- 使用搜索框按名称、Agent 或执行说明查找自动化，并按草稿、已启用或已暂停筛选。
- 打开详情后，可以编辑任务。保存编辑会生成新版本，后续运行使用新版本。
- 只有已启用的自动化可以选择 **立即运行**。
- 关闭卡片开关会暂停自动化。暂停期间错过的定时任务不会补跑。
- 打开 **运行历史** 可以查看每次运行的时间、版本、状态和结果摘要。仍在排队或运行中的任务可以停止。

## 批准客户触达

客户触达不会因为到达运行时间就直接发送：

1. 打开该自动化的 **运行历史**。
2. 对“等待批准”的记录选择 **审核并批准**。
3. 核对受众、渠道、收件人数和消息预览。
4. 选择 **批准并执行** 才会继续发送；选择 **拒绝本次执行** 则结束本次运行。

预览生成后，本次受众和文案保持固定，不会在批准时临时扩大。批准表示允许进入发送流程；最终是否送达，仍应查看触达结果和真实渠道状态。

## 常见问题

- **没有可选 Agent**：先启用一个 Agent，再确认它有页面可用的只读能力。
- **没有“客户触达”可选项**：该类型只会在当前成员权限允许时显示。如果类型已经出现但没有可选内容，先选择执行 Agent，再选择 **与 Yuna 准备客户触达**；完成预览和确认后返回自动化页面。
- **“立即运行”不可用**：先启用自动化；保存草稿本身不会运行。
- **一直显示“等待批准”**：打开运行历史完成批准或拒绝。未批准不会发送。
- **运行失败**：打开运行历史查看结果摘要，修正页面提示的权限、Agent、受众或渠道问题后再试。
