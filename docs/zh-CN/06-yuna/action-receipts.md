# 查看 Yuna 执行回执

自然语言中的“好的”或“已记录”不等于操作成功。真实执行完成后，Yuna 会显示结构化回执。

## 回执应包含

- 操作结果；
- 目标对象或范围；
- 关键内容摘要；
- 投递或处理状态；
- 查看处理详情的入口。

成功后只保留一张可刷新的正式回执，不会在输入框上方再保留一张重复的“已完成”卡。单独给一位客户发送消息时，详情入口打开该客户对话；批量或分群发送时，入口打开对应的营销历史详情。

## 状态怎么理解

“已接受”表示系统已经开始处理，不一定已经送达外部渠道。“已完成”也应结合具体投递状态判断。重要消息要以客户客户端可见为最终依据。

## 没有回执

检查 Yuna 是否只生成了草稿、是否仍等待确认、工作区是否具备所需能力，以及执行是否被权限或安全门禁拒绝。
