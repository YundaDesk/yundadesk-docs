# 查看 Yuna 执行回执

自然语言中的“好的”或“已记录”不等于操作成功。真实执行完成后，Yuna 会显示结构化回执。

## 回执应包含

- 操作结果；
- 目标对象或范围；
- 关键内容摘要；
- 投递或处理状态；
- 查看执行链路的入口。

## 状态怎么理解

“已接受”表示请求进入执行链路，不一定已经送达外部渠道。“已完成”也应结合具体投递状态判断。重要消息要以客户客户端可见为最终依据。

## 没有回执

检查 Yuna 是否只生成了草稿、是否仍等待确认、工作区是否具备所需能力，以及执行是否被权限或安全门禁拒绝。
