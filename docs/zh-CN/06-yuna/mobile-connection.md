# 把 Yuna 连接到手机渠道

手机连接让指定工作区成员在产品支持的消息应用中使用 Yuna，并接收重要提醒。它不是客户渠道，不会创建客户或访客会话。

## 连接步骤

1. 打开 Yuna 的手机连接页面。
2. 选择当前页面提供的连接方式。
3. 按提示扫码、验证账号或提交必要凭证。
4. 等待状态变为已连接，再发送一条只读测试问题。

可用提供方以页面显示为准。凭证只通过安全配置流程提交。

## 会话和提醒

网页和手机使用同一工作区上下文。工作区记忆和个人偏好可以帮助 Yuna 保持一致，但手机端展示范围可能受到镜像策略和权限限制。

## 在手机上批准操作

收到系统的待批准提示后，先核对操作内容。当前对话只有一个待批准项时，回复 `/approve` 批准，或回复 `/deny` 拒绝。有多个待批准项时，使用提示中的 `/approve 编号` 或 `/deny 编号` 指定目标。

命令只能处理当前手机对话中已经展示、仍有效的审批项。过期、已处理或其他对话的审批不能通过该命令执行；重复回复不会重复执行。批准后查看执行结果，批准本身不代表操作或发送已经完成。

手机操作使用连接负责人成员的当前工作区权限；权限被撤销后，旧连接不能继续使用这些能力。

## 解除或转移

可在同一页面撤销连接、调整状态或按产品支持情况转移负责人。手机丢失、成员离职或账号异常时应立即撤销并轮换相关凭证。
