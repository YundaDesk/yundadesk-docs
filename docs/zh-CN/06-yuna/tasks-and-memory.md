# 管理 Yuna 任务和长期记忆

Yuna 任务用于集中展示需要关注的事件；Yuna 长期记忆用于减少你在不同会话中重复说明工作习惯。

## Yuna 任务

常见任务包括学习待确认、AI 回复失败、渠道投递失败、技能回归测试和主动触达待确认。点击任务标题或处理入口应进入对应的详情页面；忽略只改变任务状态，不应删除原始日志或业务记录。

已处理和已忽略任务可以在处理记录中重新查看。任务收件箱是提醒入口，不是唯一日志来源。

## Yuna 长期记忆

Yuna 可以记住：

- 工作区共享的经营和报告偏好；
- 只属于当前成员的表达和操作偏好；
- 经确认适合跨会话复用的上下文。

进入 Yuna 记忆页可以查看、纠正、删除或清空对应范围。重复表达的同一偏好会合并到同一条记录；明确且更新的偏好会自动替换旧值，并把旧值保留在版本历史中。若新的表达不够明确，Yuna 会继续使用当前可信值，不会等待人工审批，也不会让不确定内容覆盖它。已失效记录只用于说明历史，不会继续影响 Yuna。

你也可以在对话中直接说“请记住，我个人偏好……”。Yuna 会默认保存为你的个人偏好；只有你明确说“团队”或“工作区都这样”时，才会作为共享偏好保存。保存失败时，Yuna 会说明没有记住，不会把失败说成成功。

记忆默认用于辅助回答；记忆暂时不可用时，Yuna 仍应继续工作并说明限制。

## 不应该保存什么

价格、退款政策、对客承诺和标准话术不应只放在 Yuna 记忆中，应通过知识或改进建议管理。客户个人偏好属于客户记忆，不属于 Yuna 长期记忆。不要写入密码、密钥或支付信息。
