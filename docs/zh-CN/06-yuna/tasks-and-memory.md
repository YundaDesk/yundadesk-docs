# 管理 Yuna 任务和长期记忆

Yuna 任务用于集中展示需要关注的事件；Yuna 长期记忆用于减少你在不同会话中重复说明工作习惯。

## Yuna 任务

常见任务包括学习待确认、AI 回复失败、渠道投递失败、技能回归测试和主动触达待确认。点击任务标题或处理入口应进入对应的详情页面；忽略只改变任务状态，不应删除原始日志或业务记录。

已处理和已忽略任务可以在处理记录中重新查看。任务收件箱是提醒入口，不是唯一日志来源。

## Yuna 长期记忆

Yuna 可以记住：

- 工作区共享的经营和报告偏好；
- 只属于当前成员的表达和操作偏好；
- 经确认适合跨会话复用的上下文。

进入 Yuna 记忆页可以查看、纠正、删除或清空对应范围。记忆默认用于辅助回答，但检索服务不可用时，Yuna 仍应继续工作。

## 不应该保存什么

价格、退款政策、对客承诺和标准话术不应只放在 Yuna 记忆中，应通过知识或学习评审管理。客户个人偏好属于客户记忆，不属于 Yuna 长期记忆。不要写入密码、密钥或支付信息。
