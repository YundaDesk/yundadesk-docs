# 回答 Yuna 的确认问题

当请求缺少对象、范围或执行方式时，Yuna 会在输入框上方显示选择卡片，而不是自行猜测。

## 使用选择卡片

1. 阅读问题和所有选项。
2. 选择最符合当前目的的一项。
3. 等待处理中状态结束。
4. 检查 Yuna 生成的下一步、草稿或确认卡。

## 常见选择

- 只生成草稿，不执行；
- 生成预览后由你确认；
- 立即执行允许的低风险操作；
- 取消本次请求。

## 选择后没有结果

不要连续重复点击。检查是否仍显示处理中、是否缺少必要能力，以及页面刷新后任务是否保留。Yuna 说“将生成确认内容”时，后续必须出现对应草稿或卡片，否则本次操作没有闭环。
