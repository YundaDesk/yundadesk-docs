# 管理应用和工作区能力

应用和插件把店铺、CRM 或其他业务系统接入 YundaDesk。连接成功后，Yuna 和 AI 客服可以在权限允许时使用订单、客户、库存等业务信息。

## 应用与渠道

渠道负责客户消息收发；应用负责业务数据和扩展动作。一个店铺应用可能帮助安装网站组件，但店铺本身不因此变成消息渠道。

## 能力如何出现

工作区可用功能取决于产品功能、已连接渠道、已安装应用及其当前状态。安装成功不一定代表已经可以使用；还需要完成授权和必要配置。

在能力中心查看：

- 当前可直接使用的能力；
- 需要接入或配置的数据来源；
- 暂未开放的能力和可用替代方案。

## YundaDesk 翻译助理

新工作区默认安装并启用 **YundaDesk 翻译助理**。在「设置 → 聊天工具」中开启聊天翻译时，系统会把它作为默认翻译线路。

如果工作区已经选择并启用了 DeepL，系统会保留该选择。没有可用翻译应用时，系统不会保存“已开启但无线路”的翻译设置；请先在应用页恢复或安装翻译应用。

关闭「翻译访客消息」时，实时翻译也会同时关闭。查看应用需要“查看应用”权限；安装、配置、启停或卸载应用需要“管理应用”权限；修改工作区聊天翻译设置还需要“管理聊天工具”权限。每位坐席可以在聊天工具中自行设置仅影响自己的「持续翻译」。

坐席阅读翻译也适用于 AI 客服已完成的回复。只有当该回复与坐席设定的工作语言不同时，工作台才会提供「翻译」入口；AI 回复不会自动翻译，需坐席点击后才生成译文。翻译后，同一气泡内上方显示原文、下方显示译文，中间用分隔线区分。点击「隐藏翻译」可收起译文，再点击「显示翻译」即可恢复，原文始终保留。刷新页面后默认显示已有译文。译文仅供坐席阅读，不会再次发送给客户。访客消息或 AI 回复翻译失败时，原文仍会保留，可在消息下方直接重试。

## 让智能体使用连接器

Pro 和 Enterprise 工作区可以从左侧「智能体 → 连接器」，或「应用 → 自助服务 → 连接器」进入。查看需要“查看应用”权限，配置和测试需要“管理应用”权限。无套餐权益时，入口会提示升级。

列表中的 Google Public DNS 和 Microsoft Learn 示例连接可用于熟悉测试流程，无需填写密钥。选择 DNS 查询并输入 `example.com`，或选择 MCP 文档搜索并输入一个 Microsoft 产品问题，即可查看真实返回结果。示例可以修改、停用或删除，删除后不会自动恢复；要让智能体使用，仍需在目标智能体中勾选对应功能。

1. 点击「新增」，选择 API 或 MCP，填写连接名称、地址和认证信息后保存。密钥只填写在连接设置中。
2. API 连接添加功能，并配置请求、输入参数和返回字段。输入可从对话收集、填写固定值或引用当前客户属性；涉及客户专属数据时，按业务需要启用客户身份要求。
3. MCP 连接在「连接设置」中点击「发现 MCP 工具」，选择需要的工具并保存。选择工具后可查看详情、配置使用规则和测试。
4. 保存配置后，在右侧测试面板输入参数并查看结果；窄屏通过「测试功能」打开面板。查询和写操作都会实际发出请求。写操作会修改外部数据，请使用测试数据；结果不确定时先检查外部系统，不要重复测试。
5. 打开目标智能体的「连接器」页签，开启连接器并勾选允许使用的功能。可按连接整组选取，也可展开逐项选择。
6. 在智能体调试预览中提出相关问题，再到连接器「调用记录」确认是否成功调用。

打开开关并不代表智能体可以使用全部工具。功能配置变化后，如授权失效，需要重新选择。测试成功也不代表智能体已经获得授权。勾选写操作后，智能体会根据功能的使用说明和技能中的业务步骤执行，无需另行配置人工审批。涉及修改数据时，请在说明中明确所需信息和执行条件。

### 配置请求和参数

- **POST 查询**：部分查询接口要求 POST。选择 POST 后，仅在该接口确实不会修改数据时开启「只读」。保存后可实际测试，并授权给智能体查询；会修改数据的接口应保持「只读」关闭。
- **对象和数组**：参数位置选择「请求正文」，类型选择「JSON 对象」或「JSON 数组」，可传入嵌套结构。固定值和测试值填写有效 JSON，例如 `{"status":["paid"]}`。在参数说明中写清字段、取值和结构，帮助智能体收集正确输入。
- **请求头**：普通业务请求头可作为输入参数配置，例如接口版本、语言或业务范围。API Key、Token 等凭证应在连接设置的认证区域填写；自定义认证头填写服务要求的名称，不要把密钥放进参数说明或固定值。
- **返回字段**：查询功能需要选择允许智能体读取的返回字段；写操作按需选择，接口不返回内容时可留空。测试成功后先检查返回值，再授权给智能体。

### 写操作的结果核验（可选）

通常可根据接口返回的业务状态判断结果，不必额外添加查询功能。如需再次确认，可展开「结果核验（可选）」，选择同一连接中的只读功能，配置查询参数和预期结果。

请求成功不一定代表订单已履约或退款已到账，应以外部系统返回的业务状态为准。结果不确定时，先在外部系统中确认，再决定下一步。

### 功能无法选择时

在智能体「连接器」页签中展开连接，可查看每个功能的状态。停用的连接、缺少认证信息的功能，或未选择返回字段的查询功能会显示原因且无法勾选。请先回到连接器补齐配置。已有授权的功能在配置变化后会提示重新勾选；重新授权后，再用调试预览验证。

## 使用实时业务信息

当 Yuna 或 AI 客服需要查询订单、物流或客户时，只会使用当前工作区已连接且当前成员有权访问的业务信息。店铺客户同步后，Yuna 可以查询所属店铺、平台订单数和累计消费。在通讯录中选中客户后再询问 Yuna，可以把问题限定到当前客户；尚未关联消息渠道的客户只能查询，不能直接发私信。

Yuna 服务商户团队；AI 客服服务访客。通讯录中选中的客户只会作为 Yuna 的当前对象。AI 客服只能使用当前会话对应客户的信息，不能查询工作区里的其他客户。

店铺凭证应只保存在产品提供的安全配置入口中；不要把实时数据长期复制进知识库来代替应用连接。
