# SHOPLINE 使用指南

通过 SHOPLINE 应用商店安装 YundaDesk 后，先确认店铺与 YundaDesk 工作区的连接，再到店铺当前主题中开启 **YundaDesk Chat**。店铺数据连接、前台聊天显示和消息收发需要分别检查。

**已经连接店铺，只想让聊天入口显示出来？** 直接阅读[在 SHOPLINE 店铺启用并验证前台聊天](./enable-storefront-chat.md)。

| 首次安装、授权并确认工作区 | [安装并连接 SHOPLINE 店铺](./install-and-connect.md) |
| 在店铺显示聊天入口并测试消息 | [启用并验证前台聊天](./enable-storefront-chat.md) |

## 安装到可以接待的顺序

1. 在 SHOPLINE 安装公开 YundaDesk 应用并授权。
2. 登录 YundaDesk，核对店铺和工作区并确认连接。
3. 在 SHOPLINE 当前主题的**应用嵌入**中开启 **YundaDesk Chat**，保存。
4. 返回 YundaDesk，打开店铺并检测，再验证一条消息的双向收发。

**店铺数据已连接**表示数据连接可用，不表示前台聊天已经显示。**已嵌入**表示本次检测到了聊天加载，不代替消息收发测试。需要 AI 自动接待时，继续[配置 Agent 并绑定渠道](../../04-ai-customer-service/configure.md)。
