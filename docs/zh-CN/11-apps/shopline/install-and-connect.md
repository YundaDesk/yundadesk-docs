# 安装并连接 SHOPLINE 店铺

从 SHOPLINE 公开应用商店安装 YundaDesk，完成店铺授权后，登录 YundaDesk 并确认工作区。整个流程不需要复制 API 密钥，也不需要创建自定义应用。

页面中的分步演示可以暂停、前进或返回，帮助你熟悉操作位置。演示使用示例数据，不会替你授权、连接店铺或发送消息；实际操作请在自己的店铺和工作区完成。

## 开始前

- 准备有权安装应用的 SHOPLINE 店铺账号。
- 准备目标 YundaDesk 工作区的账号，并确保具备应用管理权限。
- 确认要连接的店铺。拥有多家店铺时，每次安装都要核对店铺名称和地址。

## 在 SHOPLINE 安装并授权

1. 打开 [SHOPLINE 应用商店中的 YundaDesk](https://apps.shopline.com/detail/yundadesk_connector)。也可以在 YundaDesk 的**应用**中找到 SHOPLINE，点击**前往 SHOPLINE 安装**。
2. 点击应用商店的**安装**，按提示登录 SHOPLINE 并选择目标店铺。
3. 在授权页核对 YundaDesk 应用名称、店铺和权限。应用需要读取店铺信息、客户、订单和商品，详情见[数据与权限说明](./data-and-status.md)。
4. 阅读页面中的隐私条款，确认同意后完成**授权并安装**。

## 确认 YundaDesk 工作区

1. 按跳转提示登录或注册 YundaDesk。
2. 在连接确认页核对店铺地址与当前工作区。只有确认正确后才完成连接。
3. 如果页面提示店铺已经连接，请按页面提供的继续访问或账号关联选项处理；不要为了绕过提示重复创建工作区。
4. 返回 YundaDesk，打开**应用 → SHOPLINE → 查看店铺状态**。
5. 核对店铺地址，确认**店铺数据**显示**已连接**。

提示授权过期时，从 SHOPLINE 的 YundaDesk 应用入口重新发起，不要反复使用旧的授权回跳链接。如果店铺归属其他工作区，先联系原工作区管理员，参见[工作区不匹配](./troubleshooting-and-lifecycle.md#店铺或工作区不匹配)。

## 接下来开启前台聊天

安装完成后，店铺数据可以开始同步；前台聊天还需要在 SHOPLINE 主题中开启。此时看到**待验证**或**未检测到嵌入**，应继续[启用并验证前台聊天](./enable-storefront-chat.md)，不要把主题尚未开启当作安装失败。

安装说明位于 SHOPLINE 接入状态弹窗底部左侧，使用蓝色书本图标和**安装说明**文字；点击后会在新标签页打开本专题。
