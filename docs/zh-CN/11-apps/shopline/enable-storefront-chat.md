# 在 SHOPLINE 店铺启用并验证前台聊天

在 SHOPLINE 当前主题的**应用嵌入**中开启 **YundaDesk Chat** 并保存，才能让访客看到聊天入口。完成后返回 YundaDesk 检测，再测试一条消息的双向收发。

页面中的分步演示可以暂停、前进或返回，帮助你熟悉操作位置。演示使用示例数据，不会替你授权、连接店铺或发送消息；实际操作请在自己的店铺和工作区完成。

## 开始前

- 已[安装公开应用并完成工作区连接](./install-and-connect.md)。
- SHOPLINE 账号能够编辑和保存店铺主题。
- 确认要设置的是已连接店铺当前使用的主题。

## 1. 打开店铺后台

在 YundaDesk 打开**应用 → SHOPLINE → 查看店铺状态**，核对店铺地址，点击**设置店铺前台聊天**。展开引导后，点击第一步中的**店铺后台**链接。

**在线商店**位于 SHOPLINE 店铺后台的左侧导航中。它不是 YundaDesk 中的菜单，也不在店铺面向买家的前台页面中。后台要求登录时，请登录有主题编辑权限的 SHOPLINE 账号，并确认进入同一家店铺。

## 2. 找到当前主题

1. 在 SHOPLINE 后台左侧点击**在线商店 → 店铺设计**。
2. 在**我的主题**中找到当前**已发布**的主题，点击其旁边的**设计**。

![SHOPLINE 后台左侧的在线商店与店铺设计入口](/help/assets/docs/shopline/zh/store-design-menu.png "先进入店铺后台，再打开在线商店和店铺设计")

![当前已发布主题旁边的设计按钮](/help/assets/docs/shopline/zh/current-theme.png "编辑当前已发布主题")

不要只修改备选主题。访客访问店铺时使用的是已发布主题。

## 3. 开启 YundaDesk Chat 并保存

1. 在主题编辑器左侧点击**应用嵌入**图标。
2. 找到 **YundaDesk Chat**，确认下方开发者为 **YundaDesk**。
3. 打开该组件右侧的开关。
4. 点击编辑器右上角的**保存**，等待保存完成。

![应用嵌入中已开启的 YundaDesk Chat](/help/assets/docs/shopline/zh/app-embeds.png "开启 YundaDesk Chat；聊天小部件／消息中心是另一项应用")

SHOPLINE 自带的**聊天小部件／消息中心**是另一项应用，开启它不能代替开启 YundaDesk Chat。

中文 SHOPLINE 后台使用**应用嵌入**，英文后台使用 **App embeds**。这里的名称取决于 SHOPLINE 后台语言，可能与 YundaDesk 界面语言不同。

## 4. 返回 YundaDesk 检测

1. 回到对应店铺的 **SHOPLINE 接入状态**。
2. 点击**打开店铺并检测**，让本次操作打开店铺前台。
3. 如果浏览器没有打开页面，按提示点击**继续打开店铺**。如果店铺启用了访问密码，请先通过店铺访问验证。
4. 确认前台出现 YundaDesk 聊天入口，再返回状态页查看检测结果；需要时点击**刷新状态**。

**已嵌入**表示本次检测到了聊天加载。**上次验证通过**是历史结果，要确认当前主题仍正常，请重新检测。**未检测到嵌入**时，按[聊天未显示的排查步骤](./troubleshooting-and-lifecycle.md#开启后仍未检测到嵌入)检查。

## 5. 验证双向消息

1. 在店铺前台打开 YundaDesk 聊天窗口，发送一条不含个人资料的测试消息。
2. 在对应 YundaDesk 工作区打开**收件箱**，找到这条新会话并核对店铺来源。
3. 按会话当前状态接入或接管，发送一条人工回复。
4. 回到店铺聊天窗口，确认访客实际收到了回复。

完成这四步，才说明消息收发链路通过。点击**测试连接**只检查店铺数据连接，不能代替这个测试。

需要自动回复时，继续[配置 Agent](../../04-ai-customer-service/configure.md)；需要调整聊天外观时，阅读[自定义网站 Widget](../../02-channels/customize-widget.md)。

## 更换主题后

更换或重新发布主题后，在新的当前主题中重新检查 **YundaDesk Chat** 的开关，保存后再检测。关闭主题中的 YundaDesk Chat 只关闭该主题的前台聊天，不会因此断开店铺数据连接。
