# 将 WordPress 站点连接到 YundaDesk

连接后，当前 WordPress 站点会与一个 YundaDesk 工作区建立独立绑定。站点只会获得显示公开 Widget 所需的受限配置；在你另行批准 WooCommerce 只读授权之前，YundaDesk 无法读取店铺数据。

## 开始前

- 安装并启用 YundaDesk 插件。
- 使用可以管理站点设置的 WordPress 管理员账号。
- 在 YundaDesk 中使用有权管理应用的工作区账号。
- 确认服务器可以通过 HTTPS 访问 YundaDesk。
- 先确定由哪个 YundaDesk 工作区管理该站点。同一站点同一时间只能属于一个工作区。

## 连接站点

1. 在 WordPress 后台打开**设置 → YundaDesk**。
2. 选择**连接 YundaDesk**。
3. 登录 YundaDesk；没有账号时可以先注册。
4. 核对站点地址、WordPress 与插件版本、检测到的 WooCommerce 版本和当前工作区。
5. 首次连接时，选择**确认连接站点**。重新连接时，核对页面显示的原聊天渠道并确认；只有找到多个历史渠道时才需要选择。这个步骤不会授予 WooCommerce 权限。
6. YundaDesk 提示授权已准备完成后，点击**返回 WordPress**，回到同一个 WordPress 后台页面并完成安全连接。
7. 确认连接状态为**已连接**。

返回链接只允许回到发起连接的同源 WordPress 后台。如果页面提示请求已过期，请回到**设置 → YundaDesk**重新开始，不要重复使用旧链接。

## 重新连接或恢复历史站点

从当前 WordPress 后台的**设置 → YundaDesk**重新开始连接，并确认进入正确的工作区。根据页面提供的选项处理：

如果仍显示**已连接**且没有连接按钮，但你需要重新配对或更新站点地址，请先在本页断开当前站点，等待成功提示，再选择**连接 YundaDesk**。断开期间 Widget 会暂停；不要删除其他站点。

| 页面显示 | 你需要做什么 |
|---|---|
| 重新连接此 WordPress 站点 | 核对聊天渠道，选择“确认重新连接”；保留原会话历史，不额外创建渠道 |
| 安装信息已变化的提示 | 确认该地址仍属于原网站，再恢复页面显示的聊天渠道；不确定时取消 |
| 确认站点地址变更 | 核对原地址、当前地址和原聊天渠道，选择“确认更新并连接” |
| 选择要恢复的聊天渠道 | 根据地址、上次连接时间和参考编号选择正确历史，再选择“确认恢复”；不会预先替你选中 |

普通重连不提供“新建另一条连接”。只有没有相关历史的首次连接才会建立新的聊天渠道。

不要只因为地址相同就选择一条历史连接。如果无法确定目标，请先向工作区管理员确认。恢复连接不会合并其他站点的历史，也不会重新授予 WooCommerce 访问权限。

确认后仍需点击**返回 WordPress**。回到 WordPress 检查**已连接**，再到 YundaDesk 核对站点地址和渠道，并按下文验证一条新消息。

如果页面提示连接状态已变化，请选择**刷新配对信息**并重新核对；如果原聊天渠道不可用，请联系工作区管理员检查，处理后再重新发起，不要删除其他站点来绕过提示。

## 验证前台 Widget

1. 使用无痕窗口打开一个公开页面。
2. 确认页面出现 YundaDesk 聊天入口。
3. 打开 Widget，发送一条唯一的测试消息。
4. 在 YundaDesk 工作台确认正确站点出现新的官网会话。
5. 从工作台回复，并确认访客在 Widget 中真实收到回复。

![WordPress 前台 Widget 收到真实回复](/help/assets/docs/wordpress/zh/storefront-widget.jpg "验证真实前台消息闭环")

插件只在公开渲染页面加载 Widget，不会注入 WordPress 后台、登录页、Feed 或 REST 请求。前台只会获得公开 Widget 标识，站点连接凭据和 WooCommerce 凭据不会出现在页面源码中。

## 连接多个站点

一个工作区可以管理多个 WordPress 站点。请在每个站点安装同一个插件并分别完成连接；每个站点都有独立的连接状态、Widget 配置、WooCommerce 状态和解绑生命周期。

## 在 YundaDesk 中管理当前站点

在**应用 → WordPress → 管理站点**查看当前连接数量和每个站点的完整地址。**站点聊天**和 **WooCommerce 只读数据**分别显示状态；尚未启用 WooCommerce 或尚未授予只读权限，不代表站点聊天发生故障。只读成员可以查看状态，连接和断开操作需要相应管理权限。

选择**打开 WordPress 设置**可前往该站点后台。**前往 WordPress 断开**同样只打开后台，不会直接断开；仍需在 WordPress 中确认操作。返回 YundaDesk 后，页面会重新读取状态；加载失败时选择**重试**。

详情中的**安装说明**会在新标签页打开官网的 WordPress/WooCommerce 使用指引。选择**关闭**只会关掉详情，不会断开站点或改变授权状态。

有应用管理权限且官方安装入口可用时，**关闭**旁会显示**安装到另一个站点**。点击会在新标签页打开 WordPress.org 官方插件目录；当前站点和详情保持不变。请在另一个 WordPress 站点安装插件后，分别完成连接。

断开完成的站点不再列在这里，历史会话仍保留。全部站点断开完成后，应用卡不再显示为已安装，而是恢复与首次接入相同的官方安装入口。入口可用时，WordPress 卡显示**前往 WordPress 安装**，点击会在新标签页打开 WordPress.org 插件目录，不会先打开站点管理或连接说明弹窗。WooCommerce 卡的官方安装入口也指向同一个插件；入口尚未开放时，按卡片提示处理。

已安装的插件无需重新下载，可以直接从 WordPress 后台的**设置 → YundaDesk**重新连接。历史连接的选择只在实际配对确认时出现。
