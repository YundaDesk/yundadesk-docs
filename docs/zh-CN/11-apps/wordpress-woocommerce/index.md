# WordPress/WooCommerce

YundaDesk 只使用一个 WordPress 插件。普通 WordPress 站点可以使用在线客服、AI 客服和 Widget；检测到 WooCommerce 后，同一个插件会追加可选的只读店铺能力。

- [在 WordPress 安装 YundaDesk 插件](./install-yundadesk.md)
- [将 WordPress 站点连接到 YundaDesk](./connect-yundadesk.md)
- [启用 WooCommerce 只读增强](./enable-woocommerce.md)
- [了解 WordPress 与 WooCommerce 数据和权限](./data-and-permissions.md)
- [停用、解绑、卸载和使用隐私工具](./lifecycle-privacy-troubleshooting.md)

WooCommerce 增强不需要第二个 PHP 插件。只有站点管理员另行批准只读授权后，YundaDesk 才会读取店铺数据。
