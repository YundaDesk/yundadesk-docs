# 查看 Yundastore 购物车并创建挽回优惠

开始前，确认已安装 Yundastore 应用，当前店铺已授权数据读取，并已为店铺启用前台聊天。坐席需要查看应用数据和对应会话的权限；创建优惠与批准优惠需要各自的操作权限。

## 查看全店购物车

1. 在 YundaDesk 打开**店铺数据 → 购物车**，选择要核对的店铺。
2. 在店铺前台添加商品。购物车列表会在页面保持打开时自动更新；也可以选择**刷新**，查看上次检查时间。
3. 打开对应购物车详情，核对商品名称、数量、SKU（如有）、小计和币种。小计不包含可能在结账时加入的运费或税费。

可以先加购，也可以先打开 Widget 对话再加购。正常操作不要求访客进入购物车页面或刷新店铺页面。只有已经建立同一访客的对话时，工作台才会在该会话中显示对应的当前购物车；全店列表可先显示尚未开始对话的购物车。

## 查看当前会话购物车

1. 让访客在同一家店铺打开 Widget 并发送消息。
2. 坐席打开这段会话，在右侧**店铺订单**区域查看**当前购物车**。
3. 在店铺修改数量、移除商品或清空购物车，再核对侧栏的商品和状态。侧栏会在前台自动更新，也可选择**刷新购物车**。

退出账号并由另一位客户登录后，应在新客户自己的会话中核对购物车，不要把旧会话的商品当作新客户的购物车。

| 显示状态 | 含义与下一步 |
|---|---|
| 尚未关联购物车 | 对话已建立，但还没有可确认的当前购物车；在该店铺操作购物车后再查看。 |
| 正在同步 | 已有关联，等待店铺数据到达；稍后查看更新时间。 |
| 购物车为空 | 已确认当前购物车没有商品。 |
| 已过期 | 旧购物车信息不再作为当前内容展示；让访客在店铺继续操作后重新核对。 |
| 暂不支持 | 该店铺连接目前无法提供会话购物车；检查应用连接状态。 |
| 不可用或无权读取 | 核对所选店铺、会话权限和应用授权；临时故障可稍后重试。 |
| 已移除或已清除 | 对应购物车已不可用；不要继续使用先前显示的商品。 |

如果刷新失败，页面可能标明正在显示上次成功获取的数据。此时不要把旧内容视为店铺当前状态；先检查连接和授权，再重试。

## 创建挽回优惠

1. 从**店铺数据 → 购物车**打开要处理的购物车详情，选择**创建挽回优惠**。
2. 查看当前允许的优惠类型、金额或比例上限、币种、有效期和使用次数；填写优惠码与所需参数。
3. 选择**在店铺预览并请求审批**，核对店铺返回的对象、优惠内容和风险提示。购物车或条件变化后，应重新准备并预览。
4. 具备审批权限的人员在待批准操作中独立核对并批准或拒绝。
5. 批准后继续查看操作状态；只有显示店铺回读确认成功，才将优惠视为已创建。若显示正在核对结果，请等待核对，不要重复提交。

创建优惠不会自动向访客发送消息，也不表示购物车已经结账。购物车不存在、已完成、已清除、授权失效或店铺暂时不可用时，按页面提示处理；不要把暂时无法读取理解为已删除。
