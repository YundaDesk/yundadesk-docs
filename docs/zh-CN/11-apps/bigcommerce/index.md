# BigCommerce

YundaDesk 通过 BigCommerce 单击安装流程连接店铺。安装后，客服团队可以在工作台中查看只读的客户、订单和商品上下文，并在兼容的 BigCommerce 店面启用 YundaDesk Widget。

- [安装并授权 YundaDesk BigCommerce 应用](./install-bigcommerce-app.md)
- [同步店铺数据、启用店面聊天并在工作台使用](./use-yundadesk-with-bigcommerce.md)
- [了解数据权限、多人访问、卸载与故障排查](./data-permissions-and-lifecycle.md)

YundaDesk 不要求你复制 JavaScript 或粘贴 API 密钥。店铺管理员需要明确确认工作区绑定和每个店面的 Widget 启用操作。
