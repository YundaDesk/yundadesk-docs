# 创建和管理主动触达

主动触达是在客户没有发送新消息时，按指定对象、时间或业务条件准备消息。它与自动回复不同：受众、内容和发送结果都需要单独检查。

## 开始前

- 先连接实际用于发送的客户渠道。
- 如果触达依赖订单、付款、加购或其他店铺变化，先连接能提供这些数据的应用。
- 确认负责发送的 Agent 已启用并绑定相应渠道。
- 广播、分群和审批入口还取决于当前成员权限；页面没有对应选项时，请联系工作区管理员。

## 准备主动触达

向 Yuna 说明目标、对象、渠道、消息内容和限制。例如：“为咨询后 30 分钟没有继续回复的客户准备一条跟进消息，同一客户 24 小时内最多一次，先让我检查。”

Yuna 会继续询问缺少的信息，并展示可检查的草稿或消息预览。确认前不会启用或发送任何内容。依赖的数据、渠道或权限缺失时，页面应显示未执行或不可用原因；先修正提示的问题，再继续。

给一位明确客户发送一次生日祝福或新品提醒时，让 Yuna 准备内容并核对客户和渠道，确认后再发送。一次性消息不需要创建自动化。

## 让客户触达重复运行

需要让已经准备好的触达按需、每天、工作日或每周运行时，使用 [Yuna 自动化](../06-yuna/automations.md)：

1. 打开 **Yuna → 自动化**，展开 **创建** 旁的菜单，选择 **手动设置**。
2. 页面提供“客户触达”类型时，选择该类型和执行 Agent。已有内容可以直接选择；没有可选内容时，选择 **与 Yuna 准备客户触达**，按提示确认受众、渠道、文案和发送限制，完成后返回自动化设置。
3. 选择频率并保存草稿。
4. 检查详情后启用自动化。

“与 Yuna 创建”只用于创建工作区任务自动化，不会创建客户触达。

到达运行时间不会直接向客户发送。每次运行都会先固定受众、渠道、收件人数和文案，等待有权限的成员批准或拒绝。

## 发送前检查

批准前请核对：

- 目标人群和实际收件人数是否符合预期；
- 渠道和发送 Agent 是否正确；
- 文案是否包含准确的活动、价格和承诺；
- 是否命中退订、免打扰、安静时段或频率限制；
- 当前自动化和渠道是否仍可用。

批准后不会临时扩大已固定的收件人。真实发送前如果客户退订、进入免打扰、超过频率限制或渠道不可用，人数仍可能减少。

## 查看结果

打开自动化的 **运行历史**，先确认本次运行是等待批准、成功、失败还是已取消。批准触达后，选择结果中的 **查看发送详情**，进入自动化下的客户触达发送历史，查看目标、已发送、已抑制、失败、送达、已读和回复情况。

“已发送”只表示消息进入发送流程；只有渠道返回“已送达”或“已读”时，才能确认对应状态。渠道不提供这些回执时，页面会显示不可用，不能据此推断客户已经收到。
