# 查看主动触达投递结果

不要只看“自动化已运行”就判断客户已经收到消息。应分别检查运行、批准和渠道结果。

## 查看步骤

1. 打开 **Yuna → 自动化**，找到对应任务并打开 **运行历史**。
2. 检查本次运行的时间、版本、状态和结果摘要。
3. 如果状态为“等待批准”，打开审批预览，核对受众、渠道、收件人数和发送原文，再批准或拒绝。
4. 批准后，打开页面提供的触达结果或历史记录，查看目标、已发送、已抑制和失败数量。
5. 继续查看渠道返回的“已送达”或“已读”状态。重要触达还应在真实客户渠道中抽查。

## 常见未发送原因

- 事件数据没有接入；
- 客户仍处于冷却期；
- 当前时间不允许打扰；
- 渠道或客户身份不可用；
- 当前缺少发送所需的渠道、应用或权限；
- 内容等待人工确认；
- 渠道投递失败；
- 批量触达命中的客户正在由坐席或其他 AI 接待，此时该客户可能显示为“已抑制”，不会算作渠道发送失败。

没有生成消息不一定是故障，也可能是安全门禁正确阻止了触达。

历史中的“目标 → 发送 → 送达 → 已读 → 回复”来自实际发送结果、渠道回执和客户回复。没有回执时，页面会显示未知或不可用，不应推测成功。
