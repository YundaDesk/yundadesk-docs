# 查看主动触达投递结果

一条触达从规则命中到客户收到消息，会经过触发、决策、安全检查和渠道投递。

## 查看步骤

1. 打开营销历史中的触达记录；一次性单人触达不会创建营销计划。
2. 确认真实触发事件、目标客户和发送原文。
3. 检查冷却、安静时段、同意和权限门禁。
4. 查看是否生成执行任务。
5. 选择“查看对话与执行链路”，核对 Yuna 的确认过程和本次执行记录。
6. 打开投递记录，确认渠道最终状态。

## 常见未发送原因

- 事件数据没有接入；
- 客户仍处于冷却期；
- 当前时间不允许打扰；
- 渠道或客户身份不可用；
- 当前缺少执行所需的渠道或应用能力；Yuna 会明确显示“未执行”，不会声称已发送；
- 内容等待人工确认；
- 渠道投递失败。
- 批量触达命中的客户正在由坐席或其他 AI 接待；此时该客户会计入“已抑制”，不会要求转接，也不算渠道发送失败。

没有生成消息不一定是故障，也可能是安全门禁正确阻止了触达。

历史中的“目标 → 发送 → 送达 → 已读 → 回复 → 明确付款”来自真实消息、渠道回执、客户回复和已确认付款事件。没有回执或可靠付款事件时，后续数字保持为 0 或未知，不会推测成功。
