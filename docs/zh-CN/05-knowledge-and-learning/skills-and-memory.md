# 管理 AI 技能和客户记忆

AI 技能和客户记忆解决不同问题：技能是可复用的业务能力，客户记忆只补充某一位客户的个体上下文。

## AI 技能

进入“AI → AI 技能”查看已采纳和已生成的能力。技能详情可以展示：

- 触发条件或适用问题；
- 回答步骤、所需业务信息和转人工边界；
- 学习来源和版本；
- 测试、运行和真实命中记录；
- 当前启用状态。

技能详情用于解释它会怎样处理问题，不要求商户配置内部流程。发现技能错误时，应暂停或回滚，再通过纠正和学习评审建立正确版本。

## 客户记忆

客户记忆用于保存某位客户的偏好、禁忌或长期上下文，例如语言偏好或材质过敏。它不会自动变成所有客户共用的技能。

进入“AI → 客户记忆”或客户档案查看和管理。错误记忆可以修改或删除。客户记忆不能覆盖知识库中的政策事实，也不应保存不必要的敏感信息。

## 如何选择

- 所有客户都适用的标准处理方式：AI 技能或知识。
- 只影响某位客户的偏好：客户记忆。
- 你和团队使用 Yuna 时的偏好：Yuna 长期记忆，而不是客户记忆。
