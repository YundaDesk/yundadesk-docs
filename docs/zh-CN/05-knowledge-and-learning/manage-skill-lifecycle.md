# 测试、复制、暂停、回滚和删除技能

技能是可管理的回答或执行能力。启用前应验证触发条件、执行步骤和能力边界。

## 启用前测试

1. 打开技能详情，在“场景”中选择需要验证的客户场景。
2. 查看处理步骤，确认收集信息、判断、操作、回复或转人工的顺序符合预期。
3. 运行模拟，像真实客户一样继续对话并检查最终结果。
4. 覆盖正常完成、信息缺失、工具失败、拒绝确认或转人工等与该技能结构相关的场景。
5. 检查需要的知识、已连接应用和确认步骤是否可用。

场景测试不会向客户发消息，也不会执行真实的外部操作。只有必测场景全部通过且所需能力可用时，技能才可启用。

## 查看真实调用

“日志”展示客户接待中的真实技能调用，不包含场景模拟。每条记录包含客户问题、AI 最终回答和运行状态；有关联会话时，可打开原客户对话继续检查。

## 复制到其他 Agent

需要让另一个 Agent 从相同处理方法开始时，在技能详情选择“复制到其他 Agent”，再明确选择目标 Agent。系统会在目标 Agent 下创建一份独立的测试版本，原技能不会改变。

复制不是共享绑定：两个 Agent 后续可以分别测试、修改、启用、暂停或删除自己的版本。副本不会自动启用，必须在目标 Agent 中完成测试后再启用。来源 Agent、外接 AI 和已有同名技能的 Agent 不会作为可用目标。

## 暂停技能

发现错误或业务规则变化时先暂停。暂停后 AI 不应继续自动使用该技能，但历史运行和学习来源仍应保留。

## 回滚技能

新版本表现变差时回到上一可用版本，并重新运行关键测试。回滚不是删除，后续仍可检查变更原因。

## 删除技能

确定整项技能都不应继续使用时，可在技能详情选择“删除技能”并再次确认。删除后技能不会出现在默认列表或参与 AI 接待，但历史运行、学习来源和审计记录仍会保留。只需撤回最近一次错误修改时，应优先使用回滚；需要以后恢复时，应优先使用暂停。
