# 理解知识处理状态

添加文档或同步网站后，查看处理状态，确认内容是否已可供 AI 使用。

## 常见状态

- **处理中**：内容尚未准备完成，请等待处理结束后测试回答。
- **可使用或已完成**：当前版本已成功，可使用 **测试知识** 验证。
- **失败**：当前处理没有完成；上一成功版本可能仍在使用。
- **待更新**：源内容已变化，但新版本尚未成为当前可用版本。

## 如何确认真的生效

1. 等待状态完成；
2. 在知识库顶部选择 **测试知识**，提出文档中可直接回答的问题；
3. 打开回答详情；
4. 确认回答使用了当前知识来源，而不是无关技能或没有依据的内容。

数量增加不等于质量通过。最终以可解释的真实回答为准。
