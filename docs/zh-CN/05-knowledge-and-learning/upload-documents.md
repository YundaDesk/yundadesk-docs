# 上传知识文档

上传产品说明、政策和操作资料后，系统会处理内容，让内置 AI 在回答时使用相关知识。

## 上传前

- 删除过期、重复或互相冲突的版本；
- 避免在文档中放入密钥和不必要的客户隐私；
- 使用清楚的标题和章节；
- 一份文档尽量围绕一个稳定主题。

支持 DOC/DOCX/DOCM、PPT/PPS/POT/PPTX/PPTM/PPSX/PPSM、XLS/XLSX/XLSM/XLSB、ODT/ODS/ODP、RTF、EPUB、CSV、PDF，以及 TXT、Markdown、JSON、YAML 和 EML。

## 上传步骤

1. 打开知识库文档页。
2. 选择上传文件。
3. 选择产品当前支持的文件格式。
4. 等待处理状态完成。
5. 在知识库顶部选择 **测试知识**，用文档中的真实问题测试回答和引用。

## 从 GitHub 选择资料

如果 **新建文档** 中显示 **GitHub** 选项，可以同步公开仓库中的文本资料，不需要上传整份仓库。

1. 在 **新建文档 → GitHub** 中填写公开仓库 URL；分支留空可读取默认分支。
2. 选择 **下一步**，读取目录并进入 **选择与筛选**。展开目录并勾选需要的目录或文件；点击名称也能勾选。需要全部内容时，可勾选 **整个仓库**。
3. 按需展开 **路径筛选（可选）**，填写包含和排除路径，用逗号分隔；支持 `*` 和 `**`。例如包含 `help/**`，排除 `help/examples/**`，避免把演示资料带入知识库。
4. 选择至少一种文件类型。目前可选 `.md`、`.markdown`、`.mdx`、`.txt` 和 `.rst`。
5. 选择 **下一步**，进入 **预览与导入**，检查匹配文件数量和列表，再选择 **导入并同步**。需要调整时选择 **上一步**；已选目录、文件和筛选条件会保留，修改后再进入预览。

目录选择包含其下符合过滤条件的文件，后续同步也会读取新文件；单文件选择只同步该文件。路径和文件类型同时生效，排除条件优先。没有选中文件或没有匹配结果时，不能导入。

导入按钮只在预览有匹配文件时显示。也可点击顶部已完成的步骤返回修改，未完成预览时不能直接跳到导入。没有匹配文件时，请返回修改选择或筛选条件。文件列表较长时可以在列表内滚动，底部操作保持可见。

同步后，资料会按仓库来源显示在文档列表中。在 **全部内容** 找到来源行，查看同步状态并打开右侧操作菜单：

- **立即同步**：重新读取已选择的资料；同步中请等待完成。
- **自动同步**：开启或暂停后续自动同步，刷新页面后仍会保留设置。
- **断开并保留资料**：确认后停止同步，已导入的文档仍可参与 AI 回答。
- **删除连接及资料**：确认后停止同步，将此来源的文档移入回收站，并停止使用它们回答。不会修改远端仓库或其他来源；需要资料时，可到回收站恢复文档。

已断开的旧来源也可以在列表中删除其保留资料。同步中暂不能删除或断开。如果提示限流，请稍后重试，不要连续反复点击。

## 上传后

文件出现在列表中不代表 AI 已经可以使用。只有处理成功并进入当前知识版本后，内容才会用于回答。处理失败时不要反复上传同一文件，先查看失败原因。

处理成功的文档会在状态中显示“参与 AI 回答”。如果暂时不希望 AI 使用某份文档，可以在文档操作菜单或详情页关闭“参与 AI 回答”。文档仍会保留在知识库中，但原文和由它自动生成的问答都不会用于回答；重新开启后，无需重新上传文件。被单独关闭的问答不会因此被自动恢复。
