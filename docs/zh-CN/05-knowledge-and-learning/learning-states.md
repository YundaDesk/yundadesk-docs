# 理解学习建议的状态

学习建议只是待确认提案。AI 学习页负责决定是否采纳；采纳后的内容会在对应页面继续管理。

## 状态说明

- **待确认**：等待你判断是否值得学习。
- **已采纳**：建议已生成或更新对应内容，可从建议列表前往知识库、AI 技能或客户记忆继续管理。
- **已忽略**：建议不会生效，也不应继续作为待办出现；需要时可以重新放回待确认。

可在 AI 学习页搜索问题或建议答案，并按“待确认 / 已采纳 / 已忽略”筛选。如果采纳结果是 AI 技能，仍需在技能详情中检查场景、完成模拟并发布。

风险不是生命周期状态。涉及政策、承诺、执行或敏感信息的建议会显示风险提示，并要求更严格的审核或确认。

## 确认前检查

确认客户问题、建议答案、来源依据、适用范围、有效时间和所需业务功能。没有可靠答案或依赖未连接应用的建议不应直接确认。

## 重复建议

相同意图应合并到已有学习或技能。忽略后仍反复出现相同建议时，保留示例并反馈，不要逐条重复处理。
