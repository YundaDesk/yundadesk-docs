# 理解改进建议的状态

改进建议只是待确认提案。**改进建议** 页负责决定是否采纳；采纳后的内容会在对应页面继续管理。

## 状态说明

- **待确认**：等待你判断是否值得学习。
- **已采纳**：建议已生成或更新对应内容，可从建议列表显示的去向继续管理。
- **已忽略**：建议不会生效，也不应继续作为待办出现；需要时可以重新放回待确认。

可在 **智能体 → 改进建议** 页搜索问题或建议答案，并按“待确认 / 已采纳 / 已忽略”筛选。每条建议会显示目标 Agent；处理按钮会说明采纳后是添加知识、生成技能草稿、准备触达内容还是保存客户记忆。草稿内容仍需按对应页面提示完成检查和启用。

只有可复用的知识、内容或处理方式会进入改进建议。工具、已连接应用或投递故障保留在相关 Agent、技能或触达记录中，先按页面提示诊断或重试，不会自动变成学习建议。

风险不是生命周期状态。涉及政策、承诺、执行或敏感信息的建议会显示风险提示，并要求更严格的审核或确认。

## 确认前检查

确认客户问题、建议答案、来源依据、适用范围、有效时间和所需业务功能。没有可靠答案或依赖未连接应用的建议不应直接确认。

## 重复建议

相同意图应合并到已有学习或技能。忽略后仍反复出现相同建议时，保留示例并反馈，不要逐条重复处理。
