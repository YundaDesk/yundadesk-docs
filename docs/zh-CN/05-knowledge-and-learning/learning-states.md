# 理解学习建议的状态

学习建议只是待确认内容。只有采纳成功并形成可用资产后，AI 才可能在后续接待中使用。

## 状态说明

- **待处理**：等待你判断是否值得学习。
- **有风险**：可能影响政策、承诺或执行，需要更严格检查。
- **已采纳**：建议已进入后续测试或启用阶段。
- **已忽略**：建议不会生效，也不应继续作为待办出现。

## 评审时检查

确认客户问题、建议答案、来源依据、适用范围、有效时间和所需业务功能。没有可靠答案或依赖未连接应用的建议不应直接采纳。

## 重复建议

相同意图应合并到已有学习或技能。忽略后仍反复出现相同建议时，保留示例并反馈，不要逐条重复处理。
