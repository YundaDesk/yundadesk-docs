# 理解改进建议的状态

改进建议只是待确认提案。**改进建议** 页负责决定是否采纳；采纳后的内容会在对应页面继续管理。

## 状态说明

- **待确认**：等待你判断是否值得学习。
- **已采纳**：建议已生成或更新对应内容，可从建议列表前往知识库、技能、营销或客户记忆继续管理。
- **已忽略**：建议不会生效，也不应继续作为待办出现；需要时可以重新放回待确认。

可在 **工作空间 → 改进建议** 页搜索问题或建议答案，并按“待确认 / 已采纳 / 已忽略”筛选。每条建议会显示目标 Agent；处理按钮按真实去向显示为“添加到知识库”“生成技能草稿”“生成营销计划草稿”或“保存客户记忆”。技能和营销草稿仍需在对应详情中检查、测试并发布。

只有可复用的知识、内容或处理方式会进入改进建议。运行时、工具、Provider 或投递故障保留在相关 Agent、技能或营销记录中，先诊断或重试，不会自动变成学习建议。

风险不是生命周期状态。涉及政策、承诺、执行或敏感信息的建议会显示风险提示，并要求更严格的审核或确认。

## 确认前检查

确认客户问题、建议答案、来源依据、适用范围、有效时间和所需业务功能。没有可靠答案或依赖未连接应用的建议不应直接确认。

## 重复建议

相同意图应合并到已有学习或技能。忽略后仍反复出现相同建议时，保留示例并反馈，不要逐条重复处理。
