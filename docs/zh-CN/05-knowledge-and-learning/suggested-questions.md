# 了解知识库推荐问题

推荐问题帮助访客开始咨询。网站 Widget 可以使用接待智能体的自动推荐，也可以使用你保存的自定义问题。

## 管理 Widget 推荐问题

进入“智能体”，打开负责网站接待的内置 Agent，选择“推荐问题”：

1. 首次生成完成后，系统会保留这组推荐问题，无需先编辑再保存。重新进入页面仍显示同一组；合适的问题不足时，列表可能少显示或不显示。
2. 点击下方“知识库推荐问题”的问题气泡，或点击“添加问题”填写自己的问题。
3. 使用铅笔编辑、垃圾桶删除，拖动左侧手柄调整顺序。行内编辑完成后点击“确认问题”。
4. 在右侧“调试预览”试用，再点击页面顶部“保存”。“放弃更改”恢复上次保存的列表。

自定义状态下，“恢复自动推荐”位于“添加问题”左侧；点击后再保存，可重新使用自动推荐。同一 Agent 接待的网站共用这组问题，各网站的显示开关独立。

自定义问题只设置提问文本。点击后，AI 会正常回答；保存前请在调试预览中确认答案。问题会按 Widget 界面语言显示；翻译暂不可用时，不显示另一种语言的原文。

## 推荐内容来自哪里

自动推荐基于该 Agent 可用的知识。业务介绍、核心产品或服务、适用对象和入门说明，有助于形成适合首次咨询的问题。

推荐结果仍需检查。请确认问题与主营业务相关、知识中有明确答案，并且不需要访客先提供订单号等个人信息。

## 在哪里显示

进入“渠道”，选择网站 Widget，展开“展示设置”，找到“推荐问题”：

- **聊天首页**：在“与客服对话”和“联系我们”之间显示问题列表。
- **空白对话**：在首次空对话的欢迎语下方显示同一组问题，访客发送第一条消息后隐藏。

在 Agent 的“推荐问题”标题栏，点击“添加问题”左侧的“去配置开关”。只绑定一个网站时直接进入该网站的配置；绑定多个网站时，先从菜单中选择渠道。

两个开关互不影响。点击“推荐问题”旁的“管理”，可打开对应 Agent 的配置。

访客只会看到当前渠道已启用内置接待智能体的问题。自动推荐还需要开启该 Agent 的知识检索；人工接待、未绑定或 Agent 不可用时不显示。

Agent 的“调试预览”可用于试用正在编辑的问题。“知识库 → 测试知识”中的问题用于检查回答，不会修改访客看到的列表。

## 什么时候更新

知识更新并处理成功后，重新打开或刷新推荐问题页面，查看新候选。新候选不会自动替换已经展示的问题。

已保存的展示列表不会被知识更新覆盖。它会在下一次 Widget 加载时使用；下方候选仍会跟随知识变化。

## 重新生成推荐问题

在 Agent 的“推荐问题”中，点击“知识库推荐问题”右侧的“重新生成推荐问题”。此操作需要知识管理权限，并已启用该 Agent 的知识检索。

按钮显示“生成中…”时，刷新或离开页面不会中断生成，返回页面可查看状态和结果。资料未变化时，生成期间和失败后会保留上一组候选；失败后可再次生成。

重新生成只更新下方候选，保留当前展示列表。选入或编辑合适的问题后，点击页面顶部“保存”应用。

如果网站内容刚刚变更，请先在知识库同步网站。“重新生成推荐问题”使用当前已保存的资料，不会重新抓取网页，也不保证每次都生成不同的问题。

## 对推荐结果不满意时

- **调整展示内容**：选入候选后编辑、删除或排序，也可以自己添加问题，再保存。
- **改善自动推荐**：补充或修正该 Agent 使用的业务介绍、核心产品、适用对象和入门说明，等待处理完成后重新生成。
- **仍不合适**：直接编辑并保存展示列表，无需反复生成。

“恢复自动推荐”会替换自定义展示列表；“重新生成推荐问题”会更新候选，两者用途不同。
