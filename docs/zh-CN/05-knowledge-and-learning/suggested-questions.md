# 了解知识库推荐问题

推荐问题帮助访客快速开始咨询，也帮助商户在测试对话中验证知识。网站 Widget 可使用接待 Agent 的知识库自动推荐，也可使用你为该 Agent 设置的自定义问题。

## 管理 Widget 推荐问题

进入“智能体”，打开负责网站接待的内置 Agent，选择“推荐问题”：

- 尚未编辑时，列表默认显示该 Agent 知识范围中的 3 个推荐问题；合适的问题不足时按实际数量显示。
- 点击下方“知识库推荐问题”的问题气泡，将它加入列表；也可点击“添加问题”填写自己的问题。
- 使用每行的铅笔编辑、垃圾桶删除，拖动左侧手柄调整顺序。行内编辑完成后点击“确认问题”，再点击页面顶部“保存”。“放弃更改”恢复上次保存的列表。
- 列表可混合知识库问题和自定义问题，最多 4 个，不重复，每个最多 120 字。调整后按你保存的顺序展示；自定义状态下，“恢复自动推荐”按钮位于“添加问题”左侧；点击后再保存，可重新交由知识库自动推荐。

自定义只设置提问文本，不设置答案或保证 AI 能回答。访客点击后仍走正常的 AI 回答流程。问题会按 Widget 界面语言翻译；翻译暂不可用时，不显示另一种语言的原文。

同一 Agent 接待多个网站时共用这组问题。各网站的显示开关仍独立。Agent 配置页右侧的“调试预览”同步显示当前正在编辑的问题，方便保存前试用。

## 推荐问题如何生成

系统会综合该 Agent 当前可用的知识内容，生成适合首次咨询的问题：

- 围绕主营业务，帮助新访客了解产品或服务、核心用途、适用对象和如何开始的问题；
- 能从知识原文获得明确答案的问题；
- 不依赖订单号、实时库存或尚未连接应用的问题；
- 不包含内部信息、敏感信息或临时上下文的问题。

系统会尽量保持主题多样，避免重复相似问题。可用于回答的条款细节、少见例外或深层故障问题，不一定适合主动推荐。合适的问题不足时会少显示或不显示，不会为了凑满数量补入边缘问题。

## 在哪里显示

- **网站组件首页**：开启“首页显示推荐问题”后，在“与客服对话”和“联系我们”之间用一个列表卡片显示最多 4 个问题，问题之间用横线分隔；点击后立即作为真实访客消息进入对话。
- **首次空会话**：开启“空对话显示推荐问题”后，如果访客先进入对话而没有选择首页问题，欢迎语下方显示同一组问题，顺序不变；访客发出第一条消息后隐藏。
- **Agent 调试预览**：空对话显示当前欢迎词和问题列表；点击“重新开始”后重新展示，刷新不会带回重新开始前的旧消息。
- **知识测试对话**：可使用“换一组”查看其他知识验证问题，与 Agent 的展示列表分开。

点击问题后，它会作为真实问题进入正常的 AI 回答流程，而不是直接展示静态答案。

进入“渠道”，选择网站 Widget，展开“展示设置”，调整“首页显示推荐问题”和“空对话显示推荐问题”。两个开关互不影响，可以只保留其中一个位置；普通聊天不受影响。需要编辑内容时，点击“首页显示推荐问题”开关旁的“管理推荐问题”，直接打开所选 Agent。

访客只看到当前渠道已启用内置接待 Agent 的问题。自动模式还需要开启知识库检索；自定义模式不依赖知识编译。人工接待、未绑定或 Agent 不可用时不显示问题，但可以预先设置显示开关。

## 什么时候更新

更新知识内容并处理成功后，重新打开或刷新推荐问题页面，系统会自动生成新候选。自动模式随之更新；内容相近时，问题可能不变。已移除或不再可用的资料不会继续用于推荐。

自定义问题在 Agent 保存后用于下一次 Widget 加载，不会被知识同步覆盖；下方“知识库推荐问题”仍会跟随知识更新。

## 重新生成推荐问题

在 Agent 的“推荐问题”中，点击“知识库推荐问题”右侧的“重新生成推荐问题”。需要有知识管理权限，并已启用该 Agent 的知识检索。

此操作直接根据当前已保存的资料重新生成问题，不需要等待整库重新处理。按钮显示“生成中…”；刷新、离开页面再回来，任务仍会继续，完成后自动显示结果。重复点击不会同时启动多个任务。

资料没有变化时，生成期间保留上一组候选；失败时仍保留这组问题，可再次生成。自动模式更新展示列表；自定义模式保留你编辑的问题，只更新下方候选。

如果网站内容刚刚变更，请先在知识库同步网站；“重新生成推荐问题”不会重新抓取网页。内容没有变化时，也可以重新生成，但不保证每次都会生成不同的问题。

## 对推荐结果不满意时

- **只想调整展示内容**：将候选选入上方列表后编辑、删除或排序，也可以自己添加问题，然后保存。下方候选本身不能直接编辑。
- **希望改善自动推荐**：到知识库补充或修正该 Agent 使用的业务介绍、核心产品或服务、适用对象和入门说明，等待处理成功后重新查看候选，也可点击“重新生成推荐问题”。若仍不合适，直接编辑并保存展示列表，无需反复生成。
- **希望恢复自动选择**：点击“添加问题”左侧的“恢复自动推荐”，再保存。此操作会替换自定义展示列表，不会重新生成一批候选。
