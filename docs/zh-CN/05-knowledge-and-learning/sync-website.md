# 同步网站内容

网站同步适合公开、稳定并允许抓取的帮助内容。登录后页面、动态订单信息和客户数据不应通过网站抓取进入知识库。

## 添加网站

1. 打开知识库并选择网站来源。
2. 输入允许访问的完整起始地址。系统默认使用 HTTPS；如果公开网站确实只支持 HTTP，请明确输入以 `http://` 开头的地址。
3. 检查系统发现的页面范围。
4. 启动同步并等待处理完成。
5. 用关键页面的问题在调试台验证。

## 网站更新后

重新同步会生成新的知识版本。新版本成功前，系统应继续使用上一成功版本；失败的同步不应清空现有可用知识。

网站菜单中的“自动同步”和“参与 AI 回答”互不影响。暂时不希望 AI 使用某个站点时，可以关闭“参与 AI 回答”：已有页面及其自动生成的问答会停止参与回答，但内容和同步计划仍会保留。重新开启后无需重新添加网站。

## 抓取不到内容

知识库右上角的铃铛会显示需要处理的抓取消息，打开后可查看失败页面和原因。

检查页面是否公开、地址是否正确、网站是否阻止抓取，以及内容是否由浏览器脚本动态加载。网站证书异常可能影响同步，请修复证书后重试。若网站确实只提供公开 HTTP 且该地址可以正常访问，可使用完整的 `http://` 地址重新添加网站。不要用网站同步代替需要授权的店铺数据接口。
