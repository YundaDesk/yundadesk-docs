# 同步网站内容

网站同步适合公开、稳定并允许抓取的帮助内容。登录后页面、动态订单信息和客户数据不应通过网站抓取进入知识库。

## 添加网站

1. 打开知识库，选择 **新建文档 → 抓取网页**。
2. 输入允许访问的完整起始地址。系统默认使用 HTTPS；如果公开网站确实只支持 HTTP，请明确输入以 `http://` 开头的地址。
3. 选择是否抓取子页面；开启时，按需要设置抓取深度和页面数量上限。
4. 启动同步并等待处理完成。
5. 在知识库顶部选择 **测试知识**，用关键页面的问题验证。

网站条目会显示最近一次抓取的完整起始地址（包括路径），可据此核对抓取入口。同一域名的页面仍归在同一个网站条目下。

## 让网站客服使用这份知识

抓取完成并不等于网站客服已经使用它。打开 **智能体**，选择该网站渠道正在接待的 Agent，在 **知识范围** 中选择对应网站并保存；再到 **渠道 → 接待设置** 核对绑定的 Agent。

网站按整个来源选择，不支持逐页勾选。帮助中心、博客和营销文章可能包含不同用途或过时信息；优先从需要的帮助目录开始抓取，完成后检查实际文档列表，不要把起始路径当成已排除其他内容的证明。若同一域名以前抓过其他目录，也要检查已有内容。

不要同时让过期总文档和新网站内容提供冲突答案。替换来源时，在 Agent 的知识范围中取消旧文件或旧来源，保留新来源并保存；不必删除原文件。使用该 Agent 的 **测试对话** 查看回答详情，确认命中了新内容，并核对未支持的功能没有被说成已支持。

## 网站更新后

重新同步会生成新的知识版本。新版本成功前，系统应继续使用上一成功版本；失败的同步不应清空现有可用知识。

网站菜单中的“自动同步”和“参与 AI 回答”互不影响。暂时不希望 AI 使用某个站点时，可以关闭“参与 AI 回答”：已有页面及其自动生成的问答会停止参与回答，但内容和同步计划仍会保留。重新开启后无需重新添加网站。

## 抓取不到内容

知识库右上角的铃铛会显示需要处理的抓取消息，打开后可查看失败页面和原因。

检查页面是否公开、地址是否正确、网站是否阻止抓取，以及内容是否由浏览器脚本动态加载。网站证书异常可能影响同步，请修复证书后重试。若网站确实只提供公开 HTTP 且该地址可以正常访问，可使用完整的 `http://` 地址重新添加网站。不要用网站同步代替需要授权的店铺数据接口。
