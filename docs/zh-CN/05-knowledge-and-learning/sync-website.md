# 同步网站内容

网站同步适合公开、稳定并允许抓取的帮助内容。登录后页面、动态订单信息和客户数据不应通过网站抓取进入知识库。

## 添加网站

1. 打开知识库并选择网站来源。
2. 输入允许访问的起始地址。
3. 检查系统发现的页面范围。
4. 启动同步并等待处理完成。
5. 用关键页面的问题在调试台验证。

## 网站更新后

重新同步会生成新的知识版本。新版本成功前，系统应继续使用上一成功版本；失败的同步不应清空现有可用知识。

## 抓取不到内容

检查页面是否公开、地址是否正确、网站是否阻止抓取，以及内容是否由浏览器脚本动态加载。不要用网站同步代替需要授权的店铺数据接口。
