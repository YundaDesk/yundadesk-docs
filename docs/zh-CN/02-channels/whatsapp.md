# 连接 WhatsApp

YundaDesk 的 WhatsApp 接入使用 Meta 官方授权窗口，无需手动填写第三方服务商的 API Key。

## 准备工作

准备可管理企业资产的 Meta 账号，以及一个可用于 WhatsApp Cloud API 的业务号码。确保浏览器允许打开 Meta 授权窗口。

## 连接号码

1. 打开「渠道」，在渠道市场找到 WhatsApp，点击「接入」。
2. 等待连接准备完成，点击 **使用 Meta 登录连接**。
3. 在弹出的 Meta 授权窗口中登录，按提示选择或创建商业账户和号码。
4. 授权完成后系统自动完成剩余配置，渠道创建后默认保持停用。
5. 在渠道配置页点击 **测试连接**，检查通过后启用渠道。
6. 从客户侧发送一条消息，确认工作台收到；再从工作台回复，确认客户侧真实收到。

## 回复时间说明

WhatsApp 回复受平台会话窗口限制。若工作台提示当前不能回复，请按提示等待客户再次联系或联系 YundaDesk 支持；接入成功不代表可以随时向任何号码主动发送消息。

## 排错

- **授权窗口未打开**：允许当前站点打开弹出式窗口，再重试。
- **准备失败、授权取消或超时**：按页面提示重试，并确认 Meta 页面可正常访问；没有完成授权时不要认为已经连接。
- **号码已接入**：先核对已有渠道，避免重复连接同一号码。
- **重新授权失败**：使用原渠道对应的号码完成授权，不能通过重新授权替换成另一个号码。
- **测试连接失败或消息没有送达**：检查渠道状态和 Meta 账号权限，保留页面错误提示并联系支持。连接检测通过仍需完成真实收发验证。
