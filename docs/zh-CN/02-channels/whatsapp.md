# 连接 WhatsApp

WhatsApp 渠道提供两种接入方式，接入后收发消息的体验一致。在「渠道 → 接入 WhatsApp」页面选择适合你的方式：

- **通过 Meta 注册号码**：在 Meta 官方授权窗口中注册或迁移号码。适合还没有 WhatsApp API 号码的商家。
- **授权号码（YCloud）**：已经在 YCloud 开通了 WhatsApp 号码，粘贴账户 API Key 即可接入，号码继续保留在你的 YCloud 账户中。

## 通过 Meta 注册号码

1. 打开「渠道」，在渠道市场找到 WhatsApp，点击「接入」。
2. 选择「通过 Meta 注册号码」，点击「使用 Meta 登录连接」。
3. 在弹出的 Meta 授权窗口中登录，按提示选择或创建商业账户和号码。
4. 授权完成后系统自动完成剩余配置，渠道创建后默认保持停用。
5. 在渠道配置页点击「测试连接」，检查通过后启用渠道。

需要准备可管理企业资产的 Meta 账号，以及一个可用于 WhatsApp 的业务号码。

## 授权号码（YCloud）

### 准备工作

1. 在 [YCloud 官网](https://www.ycloud.com/) 注册账户并登录控制台。
2. 在 YCloud 控制台完成 WhatsApp 商业账户与号码的开通。
3. 在控制台的开发者设置中复制账户 API Key。

### 接入步骤

1. 打开「渠道」，在渠道市场找到 WhatsApp，点击「接入」。
2. 选择「授权号码（YCloud）」。
3. 粘贴 API Key，点击「查询可用号码」。
4. 在列表中选择要接入的号码。尚未完成开通或已被接入的号码会标注原因，无法选择。
5. 确认渠道名称，点击「完成接入」。系统会先创建渠道并自动检测连接，检测通过后自动启用。

接入完成后即可在工作台接收和回复该号码的客户消息。保存后不会再显示完整的 API Key。

### 接入后

- **检测未通过**：渠道会保存为停用状态。可稍后在接入页重试，或到渠道配置页点击「测试连接」排查后再启用。
- **更换 API Key**：在 YCloud 控制台轮换 Key 后，到渠道配置页的「新的 API Key」输入框粘贴新 Key 并保存；留空表示不更换。
- **更换号码**：在渠道配置页断开连接后重新接入；断开后原号码即可重新选择。
- **消息费用**：按你的 YCloud 账户计费，与 YundaDesk 套餐无关。

## 回复时间说明

按 WhatsApp 官方规则，客户最后一次发来消息后的 24 小时内可以自由回复；超过 24 小时后暂时无法直接回复，请等客户再次发来消息。

## 排错

- **提示 API Key 无效**：到 YCloud 控制台确认 Key 是否正确或已被轮换，复制最新的 Key 重新粘贴。
- **看不到号码**：确认该 YCloud 账户下已完成 WhatsApp 号码开通；新开通的号码可稍后重新查询。
- **号码显示“未完成开通”**：到 YCloud 控制台完成号码接入流程后再回来查询。
- **号码显示“已接入”**：同一个号码同时只能接入一次；如需换绑，请先在原渠道的配置页断开连接。
- **测试连接失败**：确认 Key 未被撤销、号码仍在该账户下且状态正常，然后重试。
