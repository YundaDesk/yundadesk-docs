# 渠道概览

渠道是客户联系你的入口。连接后，不同来源的消息会进入同一个工作台，并关联到客户档案。

## 查看可用渠道

打开“渠道”页面查看当前工作区可以连接的渠道。不同部署、套餐或集成状态下，可用渠道可能不同；页面显示是最终依据。

渠道卡片通常会显示连接状态和必要操作。只有完成配置且状态正常的渠道才能稳定收发消息。

## 接入邮件渠道

选择邮件渠道后，先从三种入口中选择：

- **Gmail**：使用 Google 官方授权连接 Gmail 或 Google Workspace 邮箱。
- **Microsoft Outlook**：使用 Microsoft 官方授权连接 Outlook 或 Microsoft 365 邮箱。
- **其他邮箱**：先填写邮箱地址。系统会按邮箱后缀识别常见服务商并预填收发信设置；无法识别时，可以在下一步手动填写邮箱服务商提供的收信和发信服务器参数。

使用“其他邮箱”时，如邮箱账号已开启两步验证，请使用服务商生成的应用专用密码或授权码，不要填写日常登录密码。连接完成后，仍需分别验证收信和发信。

## 连接渠道后的三个检查

1. **入站消息**：从客户侧发送测试消息，确认工作台能看到。
2. **人工回复**：从工作台回复，确认客户侧真实收到，而不只是后台显示成功。
3. **AI 接待**：如需 AI 回复，进入该渠道的 **接待设置**，在 **接待 Agent** 中选择负责接待的 Agent，然后从客户侧发起一轮新测试。选择 **人工接待** 表示该渠道不绑定 Agent。

## 设置接待方式

在渠道配置页展开 **接待设置**，选择 **接待 Agent**。已停用的 Agent 可以保留绑定，但启用后才会自动接待新会话。

在 **人工接待** 下，用 **自动分配会话** 控制是否自动分配给坐席，并通过 **接待成员** 选择工作区坐席或指定成员。关闭自动分配后，人工会话排队等待坐席接入。

更改会自动保存，也可以点击 **保存**。确认页面显示已保存后再离开；若保存失败，保留当前选择并点击 **保存** 重试。折叠分组时仍可查看当前配置摘要。

## 设置 Widget 外观

打开网站渠道的 **Widget 外观**。这里会显示当前工作区品牌名；点击 **修改工作区品牌名** 可前往品牌设置。

Free 套餐可以看到悬浮图标选项和 **隐藏 Powered by YundaDesk** 开关，但暂不可操作，旁边会提示 **Starter 套餐解锁**。Starter 及以上套餐可选择图标，也可开启开关，隐藏 Widget 首页和会话底部的品牌署名。关闭开关后恢复显示。

更改会自动保存。保存后刷新页面确认设置，并在右侧预览检查效果。旧渠道默认保留署名；降级为 Free 后，署名恢复显示。

## 渠道与应用的区别

网站、Telegram、邮件等消息入口属于渠道。店铺、CRM 或其他业务系统通常通过应用或插件连接，为 AI 提供订单、客户或库存能力，但它们本身不一定是消息渠道。

## 状态异常时

先打开渠道详情查看授权、凭证和连接状态。重新授权后再次做入站和出站测试。后台出现“已接受”并不等于外部平台已经最终送达；需要以客户侧实际收到为准。
