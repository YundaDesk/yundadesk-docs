# 连接个人账号云设备

如果你的工作区已开放“个人账号托管（工程预览）”，可以把页面列出的自有社交账号连接到 YundaDesk 工作台。它与对应平台的官方企业渠道不同，适合在充分了解账号风险后进行受控测试。

## 连接前准备

- 确认你有渠道管理权限，并且使用的是自己有权管理的账号。
- 准备登录时可能需要的手机、二维码扫描、验证码、PIN 或二次验证密码。
- 查看“渠道”页面当前提供的账号类型、出口选项和功能范围；不同账号类型可能不同。
- X 个人号需要 YundaDesk 支持协助完成受保护的登录步骤。

不要把账号 cookie、会话文件、验证码或代理密码发到聊天、工单正文或截图中。只在产品指定的安全输入框中提交页面要求的信息。

## 了解风险

个人账号托管不是对应平台的官方企业 API。平台可能限制个人账号、要求重新登录、改变可用功能，或者中断连接。YundaDesk 无法保证账号不会被限流或限制。

连接前必须阅读并接受页面显示的当前风险说明。YundaDesk 只连接你自己的账号，不提供账号购买、出租或转售。

个人账号托管不支持群发、分群发送或自动主动触达。AI 自动接待只有在设备登录成功且你为该设备明确开启后才会运行。

## 连接步骤

1. 打开“渠道”，找到“个人账号托管（工程预览）”。如果没有这个分组，说明当前工作区尚未开放。
2. 选择页面提供的账号类型。
3. 阅读风险说明，确认使用自有账号。
4. 选择页面当前可用的网络出口。使用自定义静态代理时，只在表单中填写所需信息。
5. 决定是否同步历史消息。历史同步是可选项，支持范围和限制以页面显示为准。
6. 创建设备，并按页面挑战完成扫码、配对、验证码、PIN、二次验证或确认操作。
7. 等待状态变为“在线”，再用另一个账号完成一次真实入站和人工回复测试。

提交验证码、PIN、密码或代理密码后，页面不会再次显示原文。如果提交失败，请重新获取或输入，不要从浏览器历史或截图中找回。

## 理解设备状态

| 状态 | 含义与操作 |
|---|---|
| 连接中 | 正在启动并建立连接，请等待页面更新。 |
| 在线 | 可以进行受支持的人工收发测试。 |
| 离线 / 重连中 | 连接暂时中断；可先等待自动恢复，再按页面提示重连。 |
| 已失效 | 登录已失效，需要重新登录。 |
| 故障 | 查看页面显示的安全错误信息；无法恢复时联系 YundaDesk 支持。 |
| 删除中 | 新消息发送已停止；设备完成删除后才会释放占用名额。 |

第三方平台的封号、限流或协议变化不会显示为 YundaDesk 服务正常，但页面应给出可判断的设备状态或错误。

## 历史消息与 AI

历史同步不会把旧消息当成新消息提醒，也不会触发 AI 回复、学习或自动触达。并非所有账号类型都支持历史同步；只以连接页面显示的能力为准。

AI 自动接待按设备单独控制。首次验证建议保持关闭，先完成稳定的人工双向收发和重连测试，再根据业务风险决定是否开启。

## 删除设备

在设备详情中选择“删除云设备”并确认。提交后不要继续发送消息。设备显示删除完成后，相关名额才会释放；删除过程中不要重复创建同一账号来绕过状态等待。

## 故障排查

- 二维码或验证码过期：选择“开始/重新登录”，使用新挑战完成登录。
- 长时间停留在连接中：检查页面要求的网络出口和地区是否仍可用，然后尝试重连。
- 显示已失效：重新登录，不要反复提交旧验证码。
- 发送结果未知：先在实际社交应用中确认是否已送达，再决定是否重新发送，以免产生重复消息。
- 页面没有托管出口或某个账号类型：该选项当前不可用；使用页面提供的其他方式，或联系 YundaDesk 支持。
- X 登录无法继续：联系 YundaDesk 支持完成受保护的接入，不要发送原始 cookie 或会话文件。

排查后仍无法恢复时，请提供设备类型、页面状态、发生时间和页面显示的安全错误码；不要附带验证码、密码、代理凭据、cookie 或会话文件。
