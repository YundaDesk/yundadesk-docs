# 连接个人账号云设备

如果你的工作区已开放“个人账号托管”，可以把页面列出的自有社交账号连接到 YundaDesk 工作台。它与对应平台的官方企业渠道不同，使用前请充分了解账号风险。

## 连接前准备

- 确认你有渠道管理权限，并且使用的是自己有权管理的账号。
- 准备登录时可能需要的手机、二维码扫描、验证码、PIN 或二次验证密码。
- 查看“渠道”页面当前提供的账号类型、出口选项和功能范围；不同账号类型可能不同。
- X 个人号需要 YundaDesk 支持协助完成受保护的登录步骤。

不要把账号 cookie、会话文件、验证码或代理密码发到聊天、工单正文或截图中。只在产品指定的安全输入框中提交页面要求的信息。

## 了解风险

个人账号托管不是对应平台的官方企业 API。平台可能限制个人账号、要求重新登录、改变可用功能，或者中断连接。YundaDesk 无法保证账号不会被限流或限制。

连接前必须阅读并接受页面显示的当前风险说明。YundaDesk 只连接你自己的账号，不提供账号购买、出租或转售。

个人账号托管不支持群发、分群发送或自动主动触达。AI 自动接待只有在设备登录成功且你为该设备明确开启后才会运行。

## 连接步骤

1. 打开“渠道”，在渠道市场底部、“社交媒体与即时通信”下方找到“个人账号托管”。如果没有这个分组，说明当前工作区尚未开放。
2. 点击对应卡片左下角的“托管…个人账号”按钮，例如“托管WhatsApp个人账号”。Telegram App 和 Zalo App 代表个人账号托管，不是官方企业渠道；已有设备名称不会随类型名称改变。
3. 填写用于辨认账号的设备名称。
4. 选择页面当前可用的网络出口。使用自定义静态代理时，填写协议、主机、端口，以及需要时的用户名和密码；不需要填写预期 IP 地区或提交住宅类型证明。代理的来源、地区选择和账号使用风险由你自行确认。
5. 决定是否同步历史消息。历史同步是可选项，支持范围和限制以页面显示为准。
6. 阅读并接受页面的服务协议与风险说明，确认使用自有账号，再创建设备；按页面步骤完成扫码、配对、验证码、PIN、二次验证或确认操作。
7. 等待状态变为“在线”，再用另一个账号完成一次真实入站和人工回复测试。

设备创建后可能需要短暂等待连接准备。进入登录步骤后，若页面提供多种登录方式，可以选择扫码或手机号；手机号使用包含国家码的完整号码，再依次输入验证码和需要时的二次验证密码。LINE 页面展示的 PIN 应在手机端输入，不是在网页回填。只使用页面当前有效的二维码，不要使用先前保存的二维码。

提交验证码、PIN、密码或代理密码后，页面不会再次显示原文。如果提交失败，请重新获取或输入，不要从浏览器历史或截图中找回。

## 理解设备状态

### 登录期限、取消与重新登录

账号登录区显示本次登录的剩余时间。刷新页面、切换标签页、关闭后重新打开，或者页面更新二维码，都不会重新计时；验证码和二次验证也需要在本次期限内完成。短暂关闭页面不会立即取消登录。

不想继续时，选择“取消本次登录”。到期或取消后，页面会停止展示登录码，并提示正在结束连接。等待清理完成、页面允许重新登录后，再选择“开始/重新登录”；不会自动重复开始。

结束本次未完成的登录不会删除云设备或代理配置，已保存的会话也会保留。账号已确认登录成功后，不会因为原登录倒计时结束而被停止。若暂时无法确认状态，先等待页面恢复，不要反复提交或创建重复设备。

### 连接与运行状态

如果显示“等待运行资源”，设备尚未取得可用运行位置，并不表示代理密码或账号错误。点击登录后，看到“登录请求已接收”或“登录请求等待中”即可等待；无需反复点击，就绪后会自动进入登录步骤。页面显示“正在准备设备出口网络”时，请等待连接结果，并按出现的代理错误提示处理。

如果提示登录请求未能完成，检查设备状态后重新发起。排队、请求已接收都不等于账号已登录；只有完成挑战并显示“在线”后才能开始收发测试。

| 状态 | 含义与操作 |
|---|---|
| 准备中 | 正在准备设备，请等待账号登录区给出的下一步。 |
| 待登录 | 设备尚未完成账号认证；按登录区当前步骤操作。 |
| 在线 | 可以进行受支持的人工收发测试。 |
| 连接异常 | 已登录账号的渠道连接中断；先等待恢复，再按提示处理。 |
| 状态待确认 | 暂时无法确认设备状态，请刷新查看，不表示账号已退出。 |
| 故障 | 查看页面显示的安全错误信息；无法恢复时联系 YundaDesk 支持。 |
| 已停止 | 设备已停止使用；如仍在删除中，以删除提示为准。 |

“设备运行中”不等于账号已登录。二维码、手机 PIN、验证码和两步验证密码只在账号登录区显示；完成当前步骤后，等待页面给出下一步或确认登录成功。正常刷新会恢复当前有效步骤，不会延长二维码有效期。Telegram 扫码后仍可能要求在网页输入两步验证密码，不需要关闭两步验证。

LINE 手机端确认成功后，仍需等待渠道页面显示已登录。如果提示登录上下文被拒绝，请重新登录；再次失败时，展开“查看错误详情”，向支持提供错误码与发生时间，不要提供二维码、PIN 或账号密码。如果提示需要更新登录客户端，请联系支持，无需反复扫码。

## 查看设备网络出口

一次出口检测失败不等于账号退出。请根据页面显示的原因处理；如有“上次成功实测”，它是带原检测时间的历史结果，不表示本次已检测成功。后续检测会继续，新的成功结果会更新当前展示。

在“渠道”打开设备详情，查看“设备网络出口”中的检测状态、出口 IP、国家／地区和检测时间。“检测成功”表示本次已取得有效的出口检测结果，不代表账号已经登录。创建后等待检测；修改代理后等待新结果，旧 IP 不再作为当前出口展示。选择“重新检测”不会注销账号或重启设备，请勿连续点击。

“地区未知”表示暂时无法确定该 IP 的归属；“检测失败”或“结果已过期”表示当前没有足够新鲜的检测结果，不等于账号登录失败。国家／地区是 IP 归属估计，不保证物理位置；会轮换出口的代理可能在不同连接上使用不同 IP，以最近实测及其时间为准。

第三方平台的封号、限流或协议变化不会显示为 YundaDesk 服务正常，但页面应给出可判断的设备状态或错误。

## 历史消息与 AI

在设备详情的“基础设置”中修改设备名称或历史同步选项；修改名称后点击“保存”。“接待设置”位于基础设置下方，单独展开后可查看 AI 自动接待开关；展开它不会收起基础设置或清空正在编辑的名称。

历史同步不会把旧消息当成新消息提醒，也不会触发 AI 回复、学习或自动触达。并非所有账号类型都支持历史同步；只以连接页面显示的能力为准。

AI 自动接待按设备单独控制。首次验证建议保持关闭，先完成稳定的人工双向收发和重连测试，再根据业务风险决定是否开启。

## 修改代理或重试连接

已登录的 Telegram 暂时断线时，先等待连接恢复，不要删除设备或反复扫码。若页面显示“设备正在自动恢复”，按显示的阶段和下一次尝试时间等待；恢复会尝试复用已有有效会话。只有明确提示账号授权失效时，才需要重新登录。若提示网络被安全保护暂停，应按错误详情联系支持，普通出口检测成功并不表示该保护已经解除。

如果旧设备登录失败后提示连接需要恢复，选择账号登录区的“恢复设备并登录”。系统会尝试恢复当前设备连接，再继续登录；无需删除或重新创建。恢复中请勿重复点击；若提示请求未能完成，检查代理后再次发起。

“网络安全保护已暂停设备连接”表示连接已被安全保护暂停，并非刚刚重新检测了代理。按页面提示联系支持处理，再查看新的出口结果；“重新检测”只更新检测结果，不负责解除安全保护。

在设备详情的“修改设备代理”中，填写完整的新代理协议、主机、端口和所需认证信息，
然后选择“更新代理并重连”。设备会断开并重新建立连接；原密码不会回显。
“代理变更已提交”不代表已经连接或登录成功，请查看设备状态。
如果结果未能确认，先刷新状态；需要重试时重新填写完整配置，不要连续重复提交。

## 删除设备

在设备详情中选择“删除云设备”并确认。提交后不要继续发送消息。设备显示删除完成后，相关名额才会释放；删除过程中不要重复创建同一账号来绕过状态等待。

## 故障排查

- LINE 手机上确认 PIN 后，仍需等待网页显示登录成功和在线。若网页显示登录失败，不要将手机确认当作已接入成功；查看最近错误，按提示重新登录并使用新二维码。
- 页面明确提示登录请求受限：先等待，再重试，避免连续点击。其他连接或登录失败不一定是限流；先刷新状态，核对代理配置，持续失败时联系支持。

- 页面提示暂时无法提交：刷新页面，重新填写代理密码后再试；如果设备列表已经出现该设备，先查看其状态，不要重复创建。

- 二维码或验证码过期：只使用页面的新挑战；如果本次登录已结束，等待清理完成后选择“开始/重新登录”。
- 长时间停留在连接中：确认代理地址、端口和认证信息正确且仍可连接，再尝试重连。
- 显示已失效：重新登录，不要反复提交旧验证码。
- 发送结果未知：先在实际社交应用中确认是否已送达，再决定是否重新发送，以免产生重复消息。
- 页面没有托管出口或某个账号类型：该选项当前不可用；使用页面提供的其他方式，或联系 YundaDesk 支持。
- X 登录无法继续：联系 YundaDesk 支持完成受保护的接入，不要发送原始 cookie 或会话文件。

排查后仍无法恢复时，请提供设备类型、页面状态、发生时间和页面显示的安全错误码；不要附带验证码、密码、代理凭据、cookie 或会话文件。
