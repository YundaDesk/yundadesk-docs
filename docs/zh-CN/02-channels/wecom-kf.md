# 连接微信客服

连接后，客户发给企业官方“微信客服帐号”的消息会进入 YundaDesk 工作台，人工坐席和 AI 客服可以在企业微信允许的会话范围内回复。

微信客服不是普通企微员工账号。普通企微员工与外部联系人的私聊、客户群消息和内部聊天不会进入这个渠道。

## 开始前准备

你需要：

- YundaDesk 工作区管理员权限；
- 可以安装第三方应用并管理微信客服帐号的企业微信管理员；
- 至少一个已在企业微信管理后台创建的微信客服帐号；
- 一个用于真实收发测试的个人微信账号；
- 当前工作区的“渠道”页面已显示微信客服，且当前套餐包含该渠道。

## 先了解完整流程

| 阶段 | 在哪里操作 | 完成标志 |
|---|---|---|
| 创建帐号 | 企业微信管理后台 | 至少有一个微信客服帐号 |
| 安装应用 | YundaDesk → 渠道 → 微信客服 | 企业授权显示“已连接” |
| 授予管理权 | 企业微信 → 微信客服 → 通过 API 管理会话消息 | 帐号在 YundaDesk 显示“可管理” |
| 导入帐号 | YundaDesk → 微信客服 | 每个帐号成为一个独立渠道 |
| 启用和验收 | YundaDesk 工作台 + 个人微信 | 客户消息和人工回复真实双向送达 |

页面上方的交互演示可以快速预览 YundaDesk 内的授权、同步和导入步骤；下面的截图对应真实企业微信后台。

## 1. 在企业微信创建微信客服帐号

使用企业微信管理员登录管理后台，打开“应用管理”，进入“微信客服”。确认微信客服应用已启用，并检查可见范围。

![企业微信中的微信客服应用总览](/help/assets/docs/wecom-kf/shared/02-wechat-customer-service-overview.png)

选择“创建帐号”，设置头像和对外展示名称。一个企业可以创建多个客服帐号；后续每个导入 YundaDesk 的帐号都会成为一个独立渠道。

![创建微信客服帐号并设置接待方式](/help/assets/docs/wecom-kf/shared/03-create-service-account.png)

企业微信原生机器人、原生人工接待人员、欢迎语和自动结束时间由企业微信管理。它们不是 YundaDesk 的坐席配置。如果企业微信原生人工接手会话，YundaDesk 会同步展示相关消息，但当前会话会进入只读状态。

## 2. 在 YundaDesk 授权企业

1. 在 YundaDesk 打开“渠道”。
2. 选择“微信客服”，然后选择“前往企业微信授权”。
3. 使用企业微信管理员完成安装授权，并同意页面列出的企业信息、企业员工信息和微信客服权限。

![企业微信第三方应用安装授权页](/help/assets/docs/wecom-kf/shared/01-install-authorization.png)

“为你提供专属客服”是企业微信提供的服务商联系选项，不决定微信客服消息是否能够接入；可按企业需要选择。完成授权后返回 YundaDesk，等待企业授权状态变为“已连接”。

## 3. 在企业微信授予帐号管理权限

企业授权完成后，YundaDesk 可以发现客服帐号，但只有被明确授权的帐号才能由 YundaDesk 管理和收发消息。

在企业微信管理后台打开“应用管理 → 微信客服”，滚动到“通过 API 管理会话消息”，选择“授权给第三方应用”。

![微信客服的通过 API 管理会话消息入口](/help/assets/docs/wecom-kf/shared/04-api-management-entry.png)

在 YundaDesk 应用所在行打开操作菜单，选择“授权客服帐号”。

![在企业微信中为 YundaDesk 授权客服帐号](/help/assets/docs/wecom-kf/shared/06-authorize-third-party-app.png)

勾选需要接入的客服帐号并确认。一个客服帐号同时只能交由一个第三方应用管理时，应先解除原应用的管理关系。

![选择交由 YundaDesk 管理的微信客服帐号](/help/assets/docs/wecom-kf/shared/07-select-service-accounts.png)

企业微信后台的菜单名称可能随版本调整。请确认授权对象是“微信客服帐号”，不是普通成员、客户联系或客户群权限。

## 4. 同步、选择并导入帐号

返回 YundaDesk 的微信客服页面，选择“同步帐号”。刚完成企业授权、但尚未分配 API 管理权时，帐号会显示“无管理权限”。

![YundaDesk 发现微信客服帐号但尚无管理权限](/help/assets/docs/wecom-kf/shared/05-discover-service-accounts.png)

完成企业微信侧授权后再次同步，帐号会变为“可管理”。勾选需要接入的帐号，然后选择“导入所选”。

![在 YundaDesk 选择并导入可管理的客服帐号](/help/assets/docs/wecom-kf/shared/08-import-service-accounts.png)

导入的含义是：

- 为每个微信客服帐号创建一个独立的 YundaDesk 渠道；
- 按客服帐号区分会话来源；
- 允许该帐号的消息进入统一工作台；
- 允许在官方会话限制内由人工或 AI 回复。

每个帐号导入后默认关闭。导入本身不会开始接收新消息或自动回复；打开对应渠道并启用后才正式生效。如需 AI 自动接待，还要在 AI 客服的接待设置中选择对应渠道。

## 5. 完成真实收发测试

1. 在企业微信管理后台取得客服帐号 A 的接入链接或二维码。
2. 用个人微信账号打开入口并发送一条带唯一标记的测试消息。
3. 在 YundaDesk 工作台确认新会话显示正确的微信客服帐号来源。
4. 从工作台发送人工回复，并在个人微信中确认真实收到。
5. 如已启用 AI 接待，再由客户发送一条新消息，确认 AI 回复真实送达。
6. 对客服帐号 B 重复测试，确认两组会话来源不会混淆。

后台显示“已发送”不等于客户已经最终收到。验收应以客户微信中的实际消息为准，并留意稍后出现的异步发送失败状态。

## 接入边界和回复限制

| 项目 | 接入后的行为 |
|---|---|
| 消息入口 | 只接收客户发给已导入微信客服帐号的消息 |
| 对外身份 | 回复始终显示为对应微信客服帐号，不显示为某位 YundaDesk 坐席 |
| 多帐号 | 每个微信客服帐号成为一个独立渠道，会话来源按帐号区分 |
| 普通企微私聊 | 不进入 YundaDesk |
| 企业微信原生人工 | 接手后仍可同步展示，但 YundaDesk 会进入只读状态 |

微信客服要求客户先发起会话。普通 API 回复同时受以下限制：

- 只能在客户最近一次发送消息后的 48 小时内回复；
- 当前回复窗口内最多发送 5 条消息；
- 客户再次发送新消息后，回复窗口和可用条数会重新计算；
- 企业微信原生客服接手、会话结束或帐号异常时，YundaDesk 不能继续普通发送。

| 工作台提示 | 可以做什么 |
|---|---|
| 可以回复 | 人工或 AI 可在剩余额度内发送 |
| 等待企业微信原生接入 | 查看消息，等待官方状态变化 |
| 企业微信原生客服接待中 | 只读查看同步消息，不能从 YundaDesk 回复 |
| 会话已结束 | 等客户再次发起新会话 |
| 回复窗口过期或额度用尽 | 等客户发送新消息后再回复 |

YundaDesk 内部的坐席分配不会改变企业微信原生接待状态。客户看到的发送身份始终是对应的微信客服帐号。

## 支持的消息

YundaDesk 可以显示客户发来的文本、常用媒体以及部分结构化卡片。工作台出站支持文本、图片、语音、视频和文件；是否能够发送仍取决于当前会话状态、回复窗口和官方限制。

如果微信昵称可以从官方资料中取得，工作台会优先显示昵称；否则显示“微信客户 #编号”作为稳定兜底。

## 同步、重新授权和解除接入

- **同步帐号**：重新读取可管理帐号和帐号状态，不会自动启用渠道。
- **重新授权**：企业授权被撤销或失效时恢复连接，不会自动启用渠道。
- **只解除 YundaDesk 接入**：停止本地收发并移除映射，企业微信中的客服帐号仍保留。
- **同时删除官方帐号**：删除企业微信中的客服帐号及其入口，影响更大且不能由 YundaDesk 恢复。

除非明确需要删除企业微信中的官方帐号，否则优先选择只解除 YundaDesk 接入。

## 故障排查

### 授权后没有帐号

确认企业微信中已经创建微信客服帐号，然后在 YundaDesk 选择“同步帐号”。若仍为空，检查企业授权是否有效。

### 帐号显示无管理权限

由企业微信管理员把该客服帐号授权给 YundaDesk 应用，再返回同步。若帐号已交给其他第三方应用管理，需先处理原管理关系。

### 客户消息没有进入工作台

确认客户使用的是该客服帐号的接入链接或二维码，而不是给普通企微员工发私聊；同时确认对应渠道已经启用。

### 回复框变为只读

查看页面给出的原因。常见原因是企业微信原生人工已接手、会话已结束、48 小时窗口过期或 5 条回复额度用尽。

### 消息先显示已发送，随后失败

企业微信可能在接受发送请求后异步报告失败。以工作台最终状态和客户微信实际收到为准；按页面提示重新授权、等待客户新消息或重试可重试的消息。
