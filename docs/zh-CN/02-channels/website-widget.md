# 安装网站聊天组件

网站聊天组件让访客无需离开网页即可发起咨询。

## 安装步骤

1. 打开“渠道”，选择网站渠道。
2. 填写渠道名称，并加入所有允许使用组件的可信网站来源，来源需要精确匹配。留空会取消来源限制，不建议用于生产环境；如果只为临时测试而留空，请在正式发布前补齐生产网站来源。YundaDesk 后台中的实时预览始终可用，不需要把后台域名加入列表。
3. 保存配置并复制页面生成的安装代码。
4. 把代码放到网站所有需要显示聊天入口的页面中，通常位于页面结束标签之前。
5. 发布网站并刷新页面。

如果通过支持的店铺应用安装，组件代码可能由应用自动接入。仍建议打开真实店铺页面完成测试。

## 验证是否成功

使用无痕窗口访问网站，打开聊天组件并发送一条消息。然后检查：

- 工作台是否出现新会话；
- 客户名称和来源是否正确；
- 人工回复能否回到组件；
- 开启 AI 接待后，AI 回复能否在组件中真实出现。

渠道配置页右侧也是同一套真实聊天组件，可以直接输入和发送消息验证接待效果，不是静态示意图。有历史时，首页只显示当前访客最近的一条会话；没有历史时，同一位置显示“与客服对话”。组件刚打开时不会自动要求邮箱；访客点击“与客服对话”后，首次对话才会按需显示邮箱表单，完成或跳过后进入消息区。最近会话已经结束也仍可查看，再次发送消息时会以同一访客身份进入新的接待会话，不会生成新的客户档案。仅打开组件、查看历史或点击入口不会产生空的排队会话。

每个网站渠道都有独立的安装标识、访客身份和历史记录；同一工作区内多个 Website Widget 的后台预览也不会共享会话。复制安装代码时应使用当前网站渠道页面生成的代码，不要把另一个 Widget 的代码重复用于不同站点。访客收起后再次打开同一个 Widget，或从会话返回首页后重新进入同一会话，都会保留当前内容、阅读位置和已经加载的品牌图片，不会重新从空白页或第一条消息加载；系统仍会在后台补充最新消息。如果 AI 仍在生成回复，返回首页或收起后重新进入同一会话时，三点等待状态也会继续显示；进入其他会话不会沿用该状态。

AI 和人工坐席的完整回复支持 Markdown 排版，包括标题、列表、引用、代码、链接和表格；较宽的表格或代码会在消息气泡内横向滚动，不会撑破聊天窗口。出于安全考虑，回复中的原始 HTML 和 Markdown 远程图片不会直接加载。

新建网站渠道会自动获得欢迎语：系统按访客浏览器语言和工作区品牌名生成，不使用渠道名称。打开当前渠道的“展示设置”，顶部的“中文 / English”页签会控制整组内容，包括首页标题、首页描述和新对话欢迎语；页签会标明“已完成、未填写或 AI 草稿”。你可以从任一已填写语言生成另一语言的可编辑草稿，检查和修改后点击“确认”，系统随后自动保存整组内容，对访客生效。右侧 Widget 和知识库推荐问题预览也会跟随当前页签，当前语言留空时不会显示另一语言的商户文案。推荐问题读取失败时会显示“加载失败”和重试入口，不会误报为当前知识库暂无问题。

联系方式统一在网站渠道独立的“联系我们”设置项中管理，不放在“展示设置”内，最多 8 项。点击“管理”后可以：

- 从已经接入的 Telegram、LINE、WhatsApp、邮箱等渠道添加；
- 手动添加经过校验的公开链接；
- 上传微信、LINE 等联系方式的二维码或图片；
- 使用胶囊开关控制是否展示，并调整顺序或删除。

这项配置需要“管理渠道”权限；只读成员可以查看，但不能修改。其他渠道的配置页只显示该渠道当前被哪些 Website Widget 使用，并提供“前往 Widget 管理”入口，不再从渠道页反向分配。如果渠道尚未识别公开地址，也可以在 Widget 管理中手动补充。

访客侧优先看到你在“管理联系方式”中配置的公开名称；通过已接入渠道添加但没有单独填写名称时，使用该渠道的配置名称。只有名称为空时，才按访客界面语言回退到标准渠道类型，例如中文显示“微信”、英文显示“WeChat”。至少启用一个公开联系方式后，首页才显示“联系我们”入口；点击后可以在组件内查看邮箱、Telegram、LINE、二维码或图片等已启用方式。首次对话要求访客填写邮箱的表单只用于识别访客，仅在点击“与客服对话”后按需出现，不会作为“联系方式”出现；如需公开客服邮箱，请单独添加邮箱联系方式。配置页右侧预览会在保存前同步显示当前启用、排序和新增的全部联系方式，并跟随当前中文 / English 预览语言；敏感配置不会展示给访客。Telegram 用户名会在渠道配置页以 `@用户名` 展示；无法自动取得时，也可以手动填写有效的公开用户名后保存。

“展示设置”中的“首页显示推荐问题”和“空对话显示推荐问题”默认分别开启，并且互不联动。知识库已有安全候选时，Widget 首页会在“与客服对话”和“联系我们”之间用一个列表卡片显示 1–3 个推荐问题，问题之间用横线分隔；点击后立即进入会话，并像普通客户消息一样走正常的 AI 回答流程。空对话开关开启时，推荐问题紧跟欢迎语下方并与欢迎消息左对齐；欢迎语暂不可用时显示在消息区顶部。访客开始聊天后空对话推荐区隐藏。

## 常见问题

- **看不到组件**：如果配置了允许域名，检查当前网站的协议、域名和端口是否精确匹配；同时检查代码是否发布、浏览器是否缓存旧页面。
- **能发但收不到回复**：检查渠道状态和消息投递记录。
- **AI 不回复**：确认网站渠道已在“AI → 接待设置”中启用，并检查 AI 用量和知识状态。
