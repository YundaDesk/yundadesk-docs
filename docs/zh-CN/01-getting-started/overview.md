# 认识 YundaDesk

YundaDesk 是面向跨境品牌和客户服务团队的全渠道 AI 客服平台。它把不同渠道的客户对话放进同一个工作台，让 AI 和人工在同一条会话中协作。

## 四个核心角色

| 角色 | 面向谁 | 主要作用 |
|---|---|---|
| AI 客服 | 你的客户 | 根据知识、技能和客户上下文自动回答，必要时转人工 |
| Yuna | 你和团队 | 查经营数据、代办配置、整理学习建议和提醒待办 |
| 工作台 | 客服团队 | 处理会话、查看客户资料、接管 AI 和协作转接 |
| 知识库 | AI 客服 | 保存商品、政策、服务说明和常见问答等可靠资料 |

一个工作区可以按售前、售后等业务职责配置多个客户接待 Agent。每个 Agent 选择一个 Role，并分别配置知识、能力、回复方式和接待渠道；一个渠道同一时间只由一个 Agent 接待。外接 AI Agent 只负责回复，不参与 YundaDesk 的托管学习。

## 一次客户咨询如何流转

1. 客户从已连接渠道发来消息。
2. 如果该渠道已绑定并启用 Agent，Agent 会结合自己的知识、能力和客户上下文生成回答。
3. 团队可以在工作台查看回答依据和处理详情。
4. AI 无法可靠回答、客户要求人工或触发转人工规则时，会话进入人工接待。
5. 坐席的优秀回答和对 AI 的纠正可以形成待确认学习，采纳后再进入 AI 能力。

## 先做什么

新工作区建议先完成四个动作：连接渠道、新建并配置 Agent、建立知识库、从 **AI Agents** 页发起 **测试对话**。确认回答可靠后，再逐步绑定更多渠道和使用主动触达。
