# 15 分钟快速开始

本指南帮助你完成一个最小可用闭环：客户能发来消息，AI 能依据你的资料回答，团队也能接管会话。

## 1. 完成工作区信息

注册后填写品牌名称和个人资料。需要多人协作时，可以稍后在设置中邀请成员并分配角色。

## 2. 连接第一个渠道

网站聊天组件通常是最快的起点：打开“渠道”，选择网站渠道，按页面提示生成并安装代码。也可以连接 Telegram。可用渠道以“渠道”页面实际显示为准。

## 3. 准备 AI 知识

打开 **工作空间**，选择 **知识库**，再选择一种方式：

- 上传商品手册、服务政策等文档；
- 添加网站地址并等待抓取和编译完成；
- 为高频问题添加明确的标准答案。

只有状态正常且已完成处理的内容才会用于 AI 回答。

首次设置时，如果你提供了网站地址，Yuna 会优先读取首页并准备几条可点击的测试问题；首页知识可回答后即可开始测试，其余页面继续在后台处理。需要等待时，页面会显示已处理页面数和真实进度。如果网站无法访问、没有读取到有效页面，或处理结束后仍没有安全的测试问题，系统会跳过这次测试，你仍可稍后在知识库中重试。

## 4. 配置 AI 接待

打开 **AI Agents**，新建或选择一个 Agent，再在“渠道”中绑定需要 AI 接待的渠道。未绑定 Agent 的渠道不会由 AI 自动回复。

## 5. 测试 Agent

打开 **AI Agents**，选择页面右上角的 **测试对话**，明确选择 Agent 后，用客户口吻提出一个资料中有答案的问题。打开回答旁的详情，检查是否命中正确知识或技能。测试满意后，再从真实网站或 Telegram 发送一条消息进行端到端验证。

## 6. 观察第一周

每天查看几条真实 AI 回答。回答错误时使用“纠正 AI”；系统发现值得学习的内容时，会生成待确认学习建议。学习在你采纳前不会生效。
