# 登录并进入工作区

使用团队成员为你创建的账号登录 YundaDesk。登录成功后，页面中的会话、客户、渠道和 AI 资产都属于当前工作区。

## 登录步骤

1. 打开团队提供的 YundaDesk 地址。
2. 输入账号和密码。
3. 完成页面要求的验证。
4. 登录后检查左侧工作区名称和右上角账号信息。

## 登录后先检查什么

- 能否打开工作台；
- 能否看到团队已连接的渠道；
- AI 页面是否显示当前工作区的配置；
- 你的角色是否拥有完成工作所需的权限。

## 更换自己的头像

1. 打开“设置 → 个人与项目”。
2. 在“坐席身份”中选择“更换头像”。
3. 选择 PNG、JPG 或 WebP 图片，文件不超过 5 MB。
4. 等待“头像已更新”提示，并检查圆形头像是否显示新图片。

需要恢复姓名首字母头像时，选择“移除头像”。每位成员只能修改自己的头像；你的修改只影响当前工作区中的成员身份。

## 无法登录

先确认地址、账号和密码没有多余空格，并尝试刷新登录页。若出现会话无法激活、账号被停用或权限不足，请把发生时间、页面提示和账号邮箱发给工作区管理员。不要发送密码或验证码。
