# 选择内置 Agent 或外接 Agent

一个工作区可以同时有内置 Agent 和外接 Agent，但单个 Agent 只使用一种回复来源。不同 Agent 可以分别绑定不同渠道。

## 内置 AI

内置 AI 使用 YundaDesk 的知识库、学习评审、AI 技能、客户记忆和回答详情。适合希望在一个系统内持续改进和检查回答的团队。

## 外接 AI

外接 AI 使用你配置的第三方接口生成客户回复。它只参与回复，不参与 YundaDesk 托管学习，也不会自动使用内置技能和学习成果。

当前可使用 OpenAI 兼容接口接入：

1. 进入“应用 → 应用商店 → AI 服务”；
2. 在“自定义 Agent API”卡片点击“前往”；
3. 在接待设置中填写接口地址、API Key 和模型，并保存配置；
4. 先在调试区验证回复，再切换为外接 AI 接待。

## 绑定渠道前检查

1. 确认新来源已配置并可用；
2. 在调试环境验证典型问题；
3. 了解外接 Agent 不会使用哪些托管学习能力；
4. 在低风险渠道完成一次真实收发测试。

选择 Agent 来源与绑定接待渠道是两件事。只有已启用且明确绑定到该 Agent 的渠道才会进入 AI 自动接待。
