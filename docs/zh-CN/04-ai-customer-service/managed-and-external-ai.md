# 选择内置 Agent 或外接 Agent

一个工作区可以同时有内置 Agent 和外接 Agent，但单个 Agent 只使用一种回复来源。不同 Agent 可以分别绑定不同渠道。

## 内置 AI

内置 AI 使用 YundaDesk 的知识库、学习评审、AI 技能、客户记忆和回答详情。适合希望在一个系统内持续改进和检查回答的团队。

## 自有 AI

接入前，在“设置 → 订阅”确认当前工作区是否支持自有 AI；费用和额度以产品页面及第三方服务说明为准。

外接 AI 使用你配置的第三方接口生成客户回复。它只参与回复，不参与 YundaDesk 托管学习，也不会自动使用内置技能和学习成果。人设、知识和回复语言在第三方维护。

## 新建外接 Agent

1. 进入“智能体”，点击“新建 Agent”。
2. 填写 Agent 名称，选择“外接 AI”。
3. 填写 OpenAI 兼容接口地址、API Key 和模型（选填），点击“创建草稿”。
4. 创建后进入该 Agent 的“外接配置”，确认接口信息并测试典型问题，再启用 Agent、绑定接待渠道。

如果页面提示当前套餐不支持，请按提示查看可用套餐。接口必须兼容 OpenAI Chat Completions；仅有 Dify 等平台名称并不保证其原生接口直接兼容，需要提供兼容端点。

以后需要更新接口或密钥时，打开该 Agent 的“外接配置”，点击“编辑外接 AI”。编辑时 API Key 留空会保留已保存的密钥。保存后再次打开可确认接口地址和密钥配置状态，不会显示明文密钥。已在接待客户的 Agent 修改接口后，后续回复使用新配置，建议先停用验证。

## 套餐降级后如何继续接待

套餐不再包含自有 AI 权益时，外接接待暂停，配置仍保留。系统不会自动切换到内置 AI。可以升级恢复权益；如果希望改用内置 AI，可新建内置 Agent 并在渠道设置中重新选择接待 Agent。

## 服务商只使用自有 AI

服务商也可以选择外接 Agent。请分别在各工作区的订阅页面确认自有 AI 和白标权益；批量合作请联系销售。

## 绑定渠道前检查

确认接口配置有效，在测试对话中验证典型问题，并在低风险渠道完成一次真实收发测试。选择 Agent 来源与绑定渠道是两件事；只有已启用且明确绑定到该 Agent 的渠道才会进入 AI 自动接待。
