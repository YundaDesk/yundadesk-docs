# 新建并配置 Agent

从主导航打开 **智能体**，按业务职责管理客户接待 Agent。一个 Agent 选择一个 Role，可以接待多个渠道；一个渠道同一时间只绑定一个 Agent。

## 新建 Agent

1. 打开 **智能体**，选择 **新建 Agent**。
2. 从页面提供的 Role 中选择最符合接待目标的一项。
3. 输入便于团队识别的 Agent 名称并确认创建。
4. 创建完成后进入该 Agent 的详情页继续设置。

新 Agent 默认不会接待客户，也不会自动占用现有渠道。Role 只确定接待目标，不会自动添加知识或开放能力。

## 完成设置

按详情页分区检查：

- **角色与行为**：确认名称、Role、服务风格、补充要求、语气和回复方式；需要创建或调整服务风格时，点击 **与 Yuna 创建/调整**；
- **知识范围**：选择该 Agent 回答时可以使用的文件、文件夹、Notion 内容或网站；
- **工具与操作**：开启该 Agent 确实需要的查询或操作工具；
- **技能**：启用或停用已经属于该 Agent 的客户接待技能；需要重复运行主动触达时，前往 **Yuna → 自动化**；
- **接待设置**：设置答不上、敏感请求和其他需要人工处理的边界；
- **接待渠道**：选择由该 Agent 接待的渠道；
- **运行记录**：查看该 Agent 最近的测试或接待记录，并打开回答详情检查依据。

如果所选渠道已经绑定其他 Agent，页面会提示转移。确认后，新客户会话使用新绑定；已经进行中的会话继续由原 Agent 处理。

服务风格用于保持同一个 Agent 稳定的自我描述、性格和表达习惯。Agent 页面只展示当前摘要；点击 **与 Yuna 创建/调整** 后，Yuna 会在当前页面以悬浮对话打开，不会中断正在查看的配置。Yuna 会读取当前服务风格，一次询问一个必要问题，了解你希望客户获得的感受、说话习惯和需要避免的表达。信息足够且要求明确后，Yuna 会直接保存并在对话中告诉你结果，不再显示额外确认卡。

Role 或技能发生切换时，服务风格仍保持不变，因此客户感受到的是同一个客服继续处理不同问题。服务风格只改变“怎么说”，不会增加知识、开放工具、绕过审批或改变业务政策；示例也不能代替知识库中的事实。建议描述可观察的行为，例如“客户着急时先给明确结论”，不要根据一次对话写永久人格判断。

也可以打开 **渠道**，进入某个渠道的 **接待设置**，在 **接待 Agent** 中直接选择负责该渠道的 Agent；选择 **人工接待** 会解除 Agent 绑定。这里与 Agent 详情的 **接待渠道** 是同一项设置，从任一处修改都会同步到另一处。选择已停用 Agent 会保留绑定，但要启用该 Agent 后才会自动接待新会话。

选择器按“文件与文件夹、Notion 与连接、网站”分区。文件夹下保留子文件层级，可以选择单个文件或整个文件夹；网站按整站选择，不提供抓取页面的单页勾选。选择文件夹、Notion 或网站后，后续同步到该范围的新内容也会自动纳入。保存前必须明确选择至少一项，系统不会自动扩大到整个知识库。

已经连接的应用或插件工具会与内置工具一起显示。尚未连接的扩展不会出现在 Agent 表单中；需要扩展时，按页面提示前往应用中心安装或连接。开启工具不会绕过成员权限。退款、取消订单、发送消息等会改变外部状态的操作，在真正执行前仍可能要求有权限的成员确认，避免误操作、资金损失或错误触达客户。

运行记录可以帮助团队复盘回答、发现知识缺口并决定后续跟进或学习建议；查看运行记录本身不会自动发送客户消息，也不会自动修改知识库或技能。

## 启用与验证

1. 在 **智能体** 页面右上角选择 **测试对话**，再选择要测试的 Agent；
2. 检查回复是否使用了正确知识和工具；
3. 检查答不上、敏感请求和转人工场景；
4. 在 **接待渠道** 中至少绑定一个已连接渠道，再从停用提示或页头的 **更多 Agent 操作** 选择 **启用 Agent**；
5. 优先使用 Web Widget 完成一轮真实入站和回复验证。

Agent 已启用但没有绑定渠道时仍不会接待客户，列表会显示为草稿。配置成功也不等于客户侧已经收到回复，最终应以客户界面可见的消息为准。

## 停用、归档或删除

Agent 的角色、知识范围、工具和接待设置属于配置；是否运行属于独立状态。保存配置不会自动启用或停用 Agent。

需要停止这个 Agent 时，在详情页打开 **更多 Agent 操作**，选择 **停用 Agent**，阅读影响后确认。停用不会解除已绑定渠道或删除配置，但这个 Agent 不再自动回复新消息，也不会发起新的主动触达；当前由 AI 接待的会话会回到待接待队列，人工仍可继续处理。页面会显示 **Agent 已停用**，之后可从提示或同一菜单选择 **启用 Agent**。重新启用只影响之后符合条件的新任务，不会自动领回已经转为待接待或人工接待的会话。

归档和删除也位于 **更多 Agent 操作**。操作前先确认渠道和进行中的会话将如何处理。工作区必须保留至少一个 Agent，因此最后一个 Agent 不能归档或删除。

## 排错

- 无法创建：刷新 Role 列表后重试；没有可选 Role 时联系管理员或 YundaDesk 支持。
- 没有自动回复：确认 Agent 已启用、渠道已连接且明确绑定到该 Agent。
- 知识、工具或技能没有生效：回到对应分区检查是否已选择并保存，再重新测试。
- 渠道无法选择：它可能已绑定其他 Agent；查看转移提示并确认目标。
