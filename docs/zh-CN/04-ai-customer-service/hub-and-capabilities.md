# 查看 AI Agents 概览和就绪状态

从主导航打开 **AI Agents**。页面直接进入 Agent 控制面，不再经过 AI 二级菜单。

## 阅读概览

顶部四项用于快速判断当前配置：

- **Agent 总数**：当前工作区的 Agent 数量；
- **接待中**：当前已启用并可接待新会话的 Agent；
- **需要处理**：因接待来源或渠道异常而暂停接待的 Agent；
- **已覆盖渠道**：已绑定到 Agent 的渠道数量。

这些数字来自当前 Agent 和渠道配置，不表示自动化任务数、节省时间或成本。

## 检查列表

列表同时显示 Agent、Role、接待渠道、就绪状态和当前状态：

- **已就绪**：当前配置可以接待客户；
- **接待来源未就绪**：内置或外接回复来源需要处理；
- **渠道不可用**：至少一个已绑定渠道当前不可用；
- **配置未完成**：Agent 仍需完成设置或绑定渠道。

使用搜索框查找 Agent；也可以按 Role 或渠道筛选。选择 Agent 名称进入详情页，继续检查角色与行为、知识库、能力、技能、接待设置、接待渠道和运行记录。需要快速验证时，使用页面右上角的 **测试对话**，并在对话框顶部明确选择 Agent。
