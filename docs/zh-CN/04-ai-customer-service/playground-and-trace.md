# 测试 Agent 回答并查看详情

测试对话用于验证当前 Agent 配置，不会把测试消息发送到客户渠道。

## 发起测试

1. 打开 **AI Agents**，选择页面右上角的 **测试对话**。
2. 在对话框顶部选择要测试的 Agent；测试结果只属于当前明确选择的 Agent。
3. 用真实客户可能使用的说法提问，不要只复制知识库标题。
4. 观察回答内容、是否转人工，以及是否取得所需业务信息。
5. 打开回答旁的 **查看详情**。Agent 配置页快速试聊中的 **查看详情** 也会在当前页面打开回答链路，不会离开正在配置的 Agent。

测试对话可能根据当前知识库显示推荐测试问题。点击推荐问题等同于发送一条普通测试消息；**换一组** 可以查看其他问题。

## 如何理解回答详情

回答详情可能包含：

- 命中的知识内容或摘要；
- 命中的 AI 技能；
- 本轮采用的 Agent 服务风格及其版本；
- 使用的客户记忆；
- 使用的已连接业务信息；
- 安全判断、转人工或降级原因。

回答详情用于解释“这条回答为什么这样生成”，不需要了解技术细节。

## 测试建议

每个重要政策至少测试三种说法：标准问法、很短的问法、带上下文或错别字的问法。需要实时业务信息的能力还要测试缺少订单号、应用不可用和无权限等边界。

如果知识库中已有答案但回答详情没有显示使用它，先检查文档状态和最新同步结果，再查看[AI 回答异常](../10-troubleshooting/ai-answering.md)。
